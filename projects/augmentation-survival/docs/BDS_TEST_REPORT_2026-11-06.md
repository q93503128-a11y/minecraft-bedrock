The test-only production wrapper seeds the saved augment level in the production BP's dynamic-property namespace; the production handler owns the effect. An exploratory probe established that BDS 1.26.62.1 emits `itemCompleteUse` for cooked beef after the vanilla food update, although stable API documentation describes this event for chargeable items. Vanilla cooked beef did not expose `minecraft:food`, so the production handler inferred the gain from adjacent server-tick saturation samples. This test does not establish event behavior for all food items or engine builds, nor exclude unrelated same-tick saturation changes.

This regression run did not test or implement `빨리 먹기`, `속공`, `긴 팔`, or `물속 작업`; the observed cooked-beef completion event is not a duration-control hook, and the attack-speed, Long Reach, and Underwater Work probes are diagnostic only. Underwater Work is assessed as C because Haste can approximate mining while submerged but cannot preserve Java's exact fractional modifier and may conflict with existing effects. It remains NOT_PORTED and is not a core candidate. Pickup Hand is a partial C-class port: the tested path preserves native item and XP award processing but introduces an entity snap and one-tick delay.

The earlier cooked-beef test initially expected hunger 20 after eating steak from hunger 10. The correct vanilla result is 18; the assertion was fixed. An initial Underwater Work probe paired amplifier 3 with the level-1 target and exposed that the provisional mapping was wrong; it failed at 3.33× versus 1.8×. The final measurement probe records amplifiers 0–4 without asserting an effect mapping. Early Pickup Hand test drafts also failed because GameTest-local coordinates were treated as world coordinates and the outside-radius control was placed within the entity-expanded boundary. The final sequential production test uses each player's world-space bounding-box center and places the control 2 blocks beyond the configured radius; all assertions pass. This 38-test run also passed Extra Piece, water-movement, Catch Breath, Quick Feet, day/night movement, Loot Scoop, and Pickup Hand coverage, plus the fishing, breathable-component, freeze-buildup, attack-speed, Long Reach, and furnace-fuel API-surface probes. Earlier failed attempts are not counted as passing results.
