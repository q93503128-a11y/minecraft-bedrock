# Asset provenance

- `source/wayfinder-portrait.png` is an original portrait generated for this project on 2026-11-07. It is not derived from a commercial game character or screenshot.
- `tools/build_ui_art.ps1` deterministically draws the Duskveil banner, equipment-slot illustration, pack mark, and button icons from original vector shapes. The packaged PNGs are checked into `RP/textures/ui/status-window/` so the add-on can be built without a graphics dependency.
- The art references Diablo IV's character overview and Elden Ring's Status screen for information hierarchy only. No screenshot, logo, character model, or game texture is included.
