# GT RPG — 세계 위협도 및 승급 도전 상세 기획

2026-11-24. 기존 사용자 확정: W=0 시작, 상한 없음, 온라인 전원 동의로 반복 가능한 승급 도전, 성공 시 +1, 실패 유지. 기존 일반/정예 적 재사용, 마지막 수호자 패턴 동일, 사망자는 종료까지 관전. 아래 웨이브 수·구성·보상·투표 UI 세부는 검토용 가안. 구현 미착수.

## 1. 시작과 투표
- 모험가의 서 → 세계 위협도 메뉴에서 현재 W, 다음 W, 예상 적 레벨, 예상 야생 몹 변화 및 보상 확인 후 승급 신청. 자연 생성 던전 입구나 재료/입장권 필요 없음. 전직 버튼과 명확히 구분. 혼자 접속 중이면 자기 동의로 시작 가능.
- 모든 접속 중 플레이어의 **명시적 동의** 필요. 거절/시간초과/동의 대상 이탈·추가 접속 발생 시 시작 전 투표 취소 후 재신청 후보. 최초 신청 시 온라인 명단 고정, 시작 직전 실제 명단 재검사. 동시에 두 개 신청 금지. 예시 제한 시간 60초(가안).
- 사용자 확정: 선택지는 '동의 및 참가', '반대'만. 동의한 접속자 전원 참가, 불참 동의 선택지 삭제. 다른 전투 세션 참가 중인 사람이 있으면 종료 후 신청/시작하는 방향(강제 이동 금지). 승급 결과 세계 전체 적용 및 참가 의무를 동의 화면에 명시.
- 전투 중 새 접속자는 투표/전투에 난입 불가. 시작 당시 전원 동의로 시작했으므로 신규 접속자 때문에 전투를 임의 중단하는 대신 현재 상태 표시 후보. 이미 다른 전투 세션 참가 중인 사람은 동시 전투 참가 금지.
- 준비 완료 후 동의한 접속자 전원이 하나의 넓은 전용 승급 투기장으로 이동. 던전처럼 여러 방을 탐험하지 않고 같은 공간에서 웨이브와 최종 수호자 전투 진행. 입장 직전 위치·차원·게임모드 기록. 다른 던전/PvP와 구역 분리. 같은 전투 공간 재사용. 공용 위협도는 진행 중 변화 없음.

## 2. 전투 구성
- 목표 위협도 T=W+1. 적 및 수호자의 대표 레벨 M=3+3T(기존 BALANCE 가안). 모든 위협도에서 같은 수호자와 패턴. 전용 신규 몬스터를 매 단계 만들지 않음.
| 목표 위협도 T | 웨이브 | 솔로 일반/정예 구성 후보 |
| --- | ---: | --- |
| 1 | 1 | 일반 4기 |
| 2~3 | 2 | 1차 일반 4기, 2차 일반 3기+정예 1기 |
| 4 이상 | 3 | 1차 일반 4기, 2차 일반 5기, 3차 일반 4기+정예 1기 |
- 이후 최종 승급 수호자 1기. 기존 일반/정예 풀에서 고르되 근접형 중심에 소수 원거리. 초기 W 낮을 때는 좀비·스켈레톤·고블린 등 익숙한 적 위주. 고난도에서도 스킬 종류나 몹 수 무한 추가 없음. 웨이브 구성은 후보 위치/종을 바꾸는 정도. 날아다니기만 해서 근접 공격 불가인 적 조합 금지.
- 참가 N명일 때 웨이브마다 일반 적 추가 min(2(N-1), 4)기 가안, 웨이브당 총 9기 상한. 정예는 마지막 웨이브 최대 1기. N 및 W로 수량 무한 확대 금지. 웨이브는 이전 적 모두 처치 후 5초 정도 준비 시간. 강제 전체 회복/스킬 쿨타임 초기화 없음, 정상 음식/회복 스킬 사용. 시간 제한 없음(장기 정체/고의 잠수 세션 회수는 별도 설계).
- 수호자: MONSTERS 5절의 3패턴(전방 강타, 직선 충격파, 원형 파동) 그대로. 기본 일반 몹 스탯 곡선에 보스 HP×15/ATK×1.8/DEF×1.5/XP×12 한 번만 적용. 파티 HP×(1+0.75(N-1)) 추가 가안, ATK 인원 배율 없음. 시작 인원 고정. 실측 전 수치 확정 아님.
- 승급 레벨 예시(솔로 수호자):
| W 현재→목표 | 수호자 레벨 | 기본 HP |
| --- | ---: | ---: |
| 0→1 | 6 | 1170 |
| 1→2 | 9 | 1620 |
| 4→5 | 18 | 2970 |
| 9→10 | 33 | 5220 |
| 19→20 | 63 | 9720 |
| 99→100 | 303 | 45720 |
- 계산 HP=15×(28+10(M-1)). W 상한 없음. 시작 지역 Lv.1~5 보호 기존 규칙 보존. 야생 일반 범위 W=0 Lv.1~5, W=1 Lv.4~8, W=5 Lv.16~20, W=20 Lv.61~65(위험 지역 오프셋 별도). 정예 확률 min(5%,1%+0.2%p×W) 기존 가안. 기본 고정 던전 레벨 유지, 던전 도전 위협도 d의 선택 상한만 W 연동.

## 3. 승패·보상
- 살아 있는 참가자가 수호자를 정상 처치하면 성공. 세계 W를 목표 T로 정확히 한 번 변경, 참가자 원래 위치/모드 복귀. 일부 사망자는 관전 상태로 종료까지 대기, 실제 기여 보상 유지 후보. 전멸/포기/시스템 중단으로 정상 성공하지 못하면 W 유지, 재도전 가능. 사망 후 재접속으로 부활 재참전 금지.
- 승급 보상의 검토안: RPG XP는 처치 기여 즉시 지급하고 실패해도 유지(던전과 같은 규칙 채택). 웨이브 일반/정예는 MONSTERS 기본 드롭률, 수호자는 보스 기본 희귀도 분포로 장비 1개 보장, 각인서 50% 후보, 모두 성공 시 확정 지급. 승급 전용 고유 장비는 초기에 만들지 않는 방향으로 두어 던전 고유 장비의 파밍 가치를 유지. 중복 승급 보너스 XP 없음. 보상 레벨은 처치 대상 M. W가 상승하는 보상 자체와 장비/XP가 핵심. 무기여자/전투 시작 이후 신규 접속자 개인 보상 없음.
- 던전과 달리 입구 일회용 없음, 승급 도전 무한 반복 가능. 성공하면 다음 T 도전, 실패 시 같은 T. 특별 강제 대기 시간/횟수 제한 미도입. W가 올라간 만큼 다음 도전/야생이 강해지고, 강화 던전 보상 레벨도 상승.
- 사망 시 RPG/일반 장비·인벤·XP 보존, 이미 사용한 소모품 복원 없음. 획득한 새 아이템은 성공 시 정산, 실패 시 폐기. 접속자 변경/전투 중 이탈·재접속은 구현 시험에서 확정할 세부. 임시 참가 파티 저장 및 관전 복귀와 월드 성공 정산을 분리하지 않아 중복 W 증가/보상 방지. 성공 이전에 월드 W 쓰지 않는다.

## 4. 검증 및 레퍼런스
- [Minecraft Dungeons Adjusting the Endgame](https://www.minecraft.net/en-us/article/dungeons-dev-blog---adjusting-endgame) 기존 보스 미션을 통한 상위 난도 개방, [Diablo III Greater Rifts](https://news.blizzard.com/en-us/article/15317478/patch-2-1-0-preview-greater-rifts) 성장 단계에 맞춘 반복 도전과 최종 수호자 보상 참고. GT RPG는 전원 동의, 무한 W, 고정 수호자 패턴, 시간제한/입장권 없음. 공식 설명만 검토, 직접 플레이/영상 분석 미실행.
- 검증: 1~4인·모든 직업(소환수 포함), W=0/1/3/20/100/1000, 적절한/낮은 장비, 다음 레벨 스탯/정예 확률, 투표 중 거절/이탈/접속/동시 신청, 관전/재접속/전멸, 수호자 마지막 피해와 서버 종료 경쟁, W 단 한 번 상승 및 보상 정산, 다른 세션 침범/복귀. NOT_RUN. 코드·BP/RP·맵 제작 금지(사용자 구현 승인 전).
