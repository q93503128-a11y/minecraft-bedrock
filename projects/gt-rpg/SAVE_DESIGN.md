# GT RPG — 저장·복구·정산 설계 (S8)
2026-11-25. 문서 설계만. 사용자 요청으로 전체 기획 감사와 함께 작성. 신규 기술 방식은 검토용이며 실제 엔진 동작 또는 구현 완료를 뜻하지 않는다. 게임 의도·수치·콘텐츠 범위는 기존 정본 유지.

## 1. 저장 대상과 단일 권위
| 범위 | 저장 필드 및 원칙 |
| --- | --- |
| 세계 | schemaVersion, world ID, revision, W, 최초 스폰 중심, 사용된 던전 입구/세션 잠금, 진행 중 세션·종료 결과·정산 작업 ID |
| 플레이어 | 월드별 영구 내부 ID, 최초 직업 선택/기본 무기 지급 여부, 현재 직업, 9직업 독립 L/XP/전직/자유 투자/미사용점, 가방/장신구, 개인 설정·읽음 상태, 확정 미수령 보상, 재접속 복귀 상태 |
| 장비 | 변경되지 않는 고유 ID·유형·획득 레벨·희귀도·옵션·고유 효과·각인·잠금, 실제 소유 위치/버전. 장착 슬롯/가방/물리 인벤의 참조 중복 금지. 소비형 동일 메타데이터는 수량/스택 단위 |
| 소환수 | 소유자·직업·슬롯/세대·생존 HP·남은 지속시간/재생성 및 CD, 활성 세션. 실제 개체 재생성 시 이전 세대 무효화 |
| 전투 세션 | 종류, 참가자/동의 상태, 세션 ID·구역 ID·세대, 원래 위치/차원/모드, d/W/T/N 스냅샷, 참가자 생존/관전/이탈, 임시 전리품, 보상 자격, 종료/복귀 상태 |
| PvP 별도 스냅샷 | PVP 정본의 결투 직전 전체 복구 항목, 경기용 상태와 완전 분리, 종료 결과와 복귀 진행 상태 |
- 서버 권위, UI는 표시 및 요청. 표시 이름을 영구 플레이어 식별자로 사용하지 않음. 실제 API의 지속 ID 및 재접속 안정성 시험 후 월드 내부 ID 매핑 확정. 모든 세계별 데이터는 월드 저장과 함께 보존. GitHub에는 소스/스키마/테스트만, 실제 개인 세이브/계정 정보 미게시.
- 기존 바닐라 인벤·상자·장비는 실제 엔진 슬롯이 소유 위치의 권위. RPG 가방·논리 장신구는 스크립트 저장. ID를 참조할 수 있으나 물리 아이템과 가상 데이터 양쪽에서 동시에 사용 가능하면 실패. 바닐라 아이템 전체를 RPG 가방에 직렬화하지 않는다.
- 공식 World/Entity/ItemStack dynamic properties 후보, World.getDynamicPropertyTotalByteCount 등의 저장량 계측 지원 문서 검색 결과 확인. ItemStack 자체 전체를 JSON으로 손실 없이 저장할 수 있다고 가정하지 않는다. RPG 고유 아이템은 필요한 필드 스키마로 복원 검토, 바닐라 전체 아이템 스냅샷이 필요한 PvP 등은 손실 없는 실제 엔진 컨테이너/검증된 직렬화 방법 비교. UUID/팩 식별자와 데이터 키 유지. 문자열/전체 용량, 비정상 종료 시 저장 경계, 파일 저장 시점·접근 가능성은 M0 확인. Script API만으로 외부 DB나 파일 시스템, 디스크 원자적 커밋을 보장하지 않음.

## 2. 변경과 복구 불변조건
- 작업마다 operation ID, 대상 ID·기대 revision, 변경 전후 소유 위치/수량, 상태(준비/적용 중/확정/복구 필요) 기록. 관련 대상 잠금 후 최신 상태 재검사. 동일 요청 재전송은 기존 결과를 반환하고 중복 지급 금지. UI 연타/오래 열린 메뉴/동시 선물/장착/삭제를 같은 검증 경로에서 처리.
- 가방↔일반 인벤↔논리 장착/선물/각인 적용은 하나의 논리 작업. 원본 사라진 뒤 실패, 목적지 생성 뒤 실패, 동시 재접속 등 중단 지점을 검증. 물리 슬롯을 읽어 실제 반영 여부를 확인하고 작업 기록과 대조. 엔진 다중 저장의 물리적 원자성이 보장되지 않으므로 무조건 재지급·스냅샷 덮어쓰기 금지. 상태 불명확 시 관련 아이템만 사용 잠금/복구 대기, 정상 소유 확인 후 처리. 기록 자체의 영속성 한계는 M0의 출시 차단 항목.
- 보상: 처치/상자/최초 지급/승급 성공/던전 입구 각각 영구 또는 세션 범위 고유 정산 키. 개인 기여별 XP/드롭 난수 결과 한 번 결정. 저장된 결과를 재시도 시 재추첨하지 않음. 실패 XP 유지, 확정되지 않은 아이템만 폐기. 가방 만석·오프라인 시 확정 회수 대기, 부분 수령도 멱등. 완료 기록은 보상 복제 재시도 방지에 필요한 범위에서 압축; 무한 W/오랜 월드에서 전체 기록이 무한히 커지지 않도록 체크포인트/압축 시험. 사용된 던전 입구 기록은 재사용 방지 유지.
- 야생 사망: 소유 RPG 장비와 가방/직업 성장 보존, 바닐라 사망 규칙 유지. 사망 전/후 이벤트 순서와 실제 떨어진 아이템 고유 ID를 대조하여 드롭·재지급 중복 금지. global keepInventory 강제 변경 금지. 선택적 보존이 엔진에서 안전하게 불가능하면 대안 승인 전 미완료. 세션 사망은 일반 인벤/XP도 보존, 사용한 소모품은 환급하지 않음. PvP만 결투 이전 상태 복원.
- 세이브 업데이트: schemaVersion별 단계적 변환, 이전 정상 데이터/월드 백업 보존, 복사 월드에서 검사 후 적용. 미확인 새 스키마/손상/용량 부족은 무조건 초기화하지 않고 안전하게 읽기 제한·복구 요청. 기존 아이템 ID/옵션/직업 레벨/W 변경 금지; 의도된 밸런스 변경과 저장 구조 변환을 구별. 초기화/삭제에는 사용자 승인 필요. 수치 한도·정밀도 검사, 오버플로는 래핑하지 않고 진단 및 대안. 무한 성장 의도 유지.

## 3. 세션 복구 상세 제안
| 상황 | 처리 후보 |
| --- | --- |
| 준비 전 취소/실패 | 원래 월드 유지, 입구/구역/참가자 잠금 해제 |
| 던전/승급 중 일시 연결 끊김 | 60초 복귀 유예 후보, 캐릭터/소환수 비활성 및 상태 보존, 원래 생존/관전 상태로만 재접속. 관전자의 부활 불가. 다른 참가자는 계속 진행; 이탈을 무한 무적/회복으로 이용 못하도록 실제 피해·캐릭터 처리 검증 |
| 유예 만료 | 해당 참가자는 이탈 처리, 세션에 재참가 불가, 안전한 원래 위치 복귀 대기. 다른 참가자 정상 진행. 이미 기여해 확보한 임시 보상은 팀 성공 시만 정산 후보. 전원 사망/이탈하면 실패 |
| 던전/승급 자발적 포기 | 솔로는 실패·복귀. 파티 개인은 이탈 처리, 전체 포기 또는 생존 참가자 없음이면 실패. 포기자의 임시 아이템 자격은 상실 후보(사망/연결 장애와 구별), XP 유지. 명시 확인 필수 |
| 서버 중단, 성공 확정 전 | 진행 세션 재개보다 안전 실패 복귀 우선 후보. XP/기존 보유 아이템 및 사용 소모품 상태 보존, 임시 아이템 폐기, 던전 입구 미사용·W 불변 |
| 성공이 영속 기록된 뒤 중단 | 결과를 뒤집지 않고 정산/입구 소모 또는 W+1/복귀를 중복 없이 이어감. 아직 성공 기록이 확정되지 않았다면 재검사 후 실패 경로. 불명확한 기록에서 W를 임의로 올리거나 보상을 중복 지급하지 않음 |
| PvP 이탈·중단 | 기존 30초 유예/기권 가안, 서버 중단 시 승패 미확정이면 무승부 후보, 양쪽 결투 직전 상태 정확 복원. 경기용 상태 폐기. 복귀 완료 전 새 경기/외부 인벤 변경 금지 |
- 세션 시작 전에 원래 위치/차원/모드 등 복구에 필요한 상태 저장 확인. 복귀 위치가 막혔으면 근처 안전 위치→안전한 월드 스폰 후보. 참가자 복귀와 저장/정산, 개체·잔류 투사체 정리, 구역 재사용 잠금 해제는 순서와 작업 ID로 연결. 기존 세계 건축을 덮어쓰지 않음.
- 승급 전원 동의·참가 및 시작 직전 명단 재검사, 승급 성공 목표 T의 단일 갱신. 시작 후 신규 접속자 난입 금지. PvP 기존 스냅샷 규칙과 별도. 던전 입구 하나당 활성 세션 1, 구역 충돌 금지. 활성 참가자 없는 세션만 유예 후 정리, 실제 진행 중인 승급에 무조건 시간제한 추가하지 않음.
- 초기 던전 파티 1~4명/입구 근처 12블록/대기방 120초 후보. 승급은 별도 4인 상한을 강제하지 않고 모든 온라인 동의·참가 원칙 우선. 5명 이상 성능 미검증 및 콘텐츠 목표와 구별. 던전 상자 개인별 1회 수령 후보(해당 상자까지 참가한 실질 전투 기여자, 무기여 관전자 제외); 마지막 보스 기여 및 상자 기록 구분. 정확 범위/수치는 사용자 검토 후.

| G4 저장 | ID·216칸/스택·장신구/아이템 메타데이터·사망 선택 보존, 강제 중단/재접속/이중 작업에서 복제·유실 없음 | 미검증 저장 경로로 실제 월드 운용 금지 |
| G5 공간/세션 | 입구 자연 생성 후보, 전용 공간/차원·안전 복귀·관전, 초기화/동시 세션/성공 복구, PvP 스냅샷 필드 복원 | 별도 공간 대안 승인, 복원 불가 상태 명시 |

## 추가 감사 경계 사항
- 야생 사망에서 보유 RPG 장비 및 RPG 가방 전체 보존은 확정. 일반 인벤의 RPG 각인서/회복 포션/전용 재료까지 장비와 동일하게 보존할지는 미결정. 기존 바닐라 인벤 사망 규칙을 적용하는 안을 검토하되 사용자 승인 전 확정하지 않는다. 지면/상자 등 플레이어 소유가 아닌 외부 보관 상태는 사망 보존에 따른 재지급 대상이 아님. 세션 사망 및 PvP 복구의 기존 별도 원칙 유지.
- XP 정산 시 발생 당시 직업/현재 활성 직업/직업 변경 revision 검증 필요. 현재 직업만 XP라는 확정 요구와 과거 교전 기록이 충돌할 수 있으므로 SYSTEMS 8절 경계 및 DEVELOPMENT_PLAN 추가 감사 참조. M1 전에 결정, 임의 XP 이전 금지.
