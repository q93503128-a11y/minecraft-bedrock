# GT RPG 상태

마지막 갱신: 2026-11-20

## 검증 요약

| 단계 | 상태 | 근거 |
| --- | --- | --- |
| 소스/외부 에셋 통합 | `PASS` | 고정된 원본 스냅샷으로 RP 에셋 재생성 성공. 라이선스와 수정 내역은 `docs/ASSET_PROVENANCE.md` 참조 |
| 정적 검사 | `PASS` | Python 정적 검사 7개, Node 성장/희귀도 단위 검사 4개, `node --check` 2개 파일 통과 |
| 재현 빌드 | `PASS` | `.mcaddon` 및 내장 BP/RP `.mcpack` 구조 검사 통과. 연속 빌드 SHA-256 일치 |
| 독립 BDS 팩 로드 | `PASS` | 공식 Bedrock Dedicated Server 1.26.65.1에서 GT RPG BP가 팩 스택에 표시되고 서버 시작. 레시피 해금 경고를 수정한 뒤 재실행 |
| 인게임 기능 | `NOT_RUN` | 플레이어가 접속한 월드에서 명령·아이템·레시피·보스/AI·애니메이션은 미확인 |
| 멀티플레이 | `NOT_RUN` | 두 클라이언트의 전투, 개인 보상, 오프라인/재접속 및 서버 재시작 복원은 미확인 |
| 시각 검수 | `BLOCKED` | 사용자가 제공할 게임 내 스크린샷/영상 대기. AI는 게임을 조작하지 않음 |

세부 BDS 환경과 제한 사항은 [BDS 로드 결과](tests/results/bds-loadcheck-1.26.65.1.md)에 기록했다. 팩을 불러와 서버가 시작된 사실은 보스 소환·렌더링·게임플레이 성공의 증거가 아니다.

## 구현 범위

- 직업 3종: 수호자(근거리 파티 보호), 추적자(조준 대상 단일 피해), 원소술사(조준 대상 주변 피해). 플레이어별 선택/진행 저장과 20초 스킬 대기시간.
- 바닐라 적 20종의 처치 경험치, 레벨 1–50, 단계별 필요 경험치와 레벨 5 단위 체력 보너스.
- 잿빛 전갈 여왕 1종: 실제 외부 전갈 모델/텍스처/애니메이션과 바닐라 보스 체력바, 기본 공격, 예고형 직선 꼬리 찌르기와 원형 독침 휘두르기, 후반 격노. 실제 클라이언트에서의 렌더/전투 품질은 미검수.
- UnRealm의 3D 대검 모델·텍스처·아이콘·포즈 애니메이션을 실제 장비에 사용하고 다섯 희귀도 변형 제공. `Modifiers` 공개 확률(40/30/20/8/2)을 보스 보상 선택에 적용.
- 길잡이, 상태/직업/도전/보상 화면은 안정 `@minecraft/server-ui` 네이티브 폼으로 구현. 전용 그래픽 UI는 실제 게임에서 검수 전.
- 보스 피해 참가자별 XP/전리품, 플레이어별 보상 표식과 오프라인 보상 대기열 구현. 동시 보스/이탈/재접속 상황의 런타임 검증은 미실행.
- 한국어를 기본 언어로 적용하고 영어 언어 키도 포함.

## 미검증 및 위험

- BDS 검증은 플레이어가 없는 별도 테스트 인스턴스의 팩 로드와 서버 기동까지만 확인했다. 명령 실행, 신규 엔티티 스폰, custom item 동작, 레시피 사용, 동적 속성 복원은 확인하지 않았다.
- BDS 콘솔에서 플레이어 없이 바닐라/커스텀 엔티티 소환을 시도했을 때 둘 다 `Unable to summon object`를 반환했다. 이것만으로 GT RPG 엔티티 문제라고 판단할 수 없어 스폰 결과는 `NOT_RUN`으로 남긴다.
- UI 입력/닫기/중복 열기, 보스 AI/패턴 타이밍/히트박스, 무기 1·3인칭 위치, 원본 애니메이션 및 텍스처 렌더링, 한국어 줄바꿈은 사용자 게임 캡처 전까지 `NOT_RUN`이다.
- 멀티플레이 2–4인, 두 보스 동시 전투, 참가자 이탈/복귀, 보상 중복 방지와 BDS 월드 재시작 복원은 미검증이다.
- 로컬 Microsoft Store 앱 패키지 메타데이터는 `1.26.6501.0`이었다. 이는 공식 게임 버전 문자열로 단정하지 않았다. 로컬 클라이언트 버전과 안정 API 런타임 호환성은 미확인이다. 팩은 안정 `@minecraft/server` 2.11.0, `@minecraft/server-ui` 2.3.0과 최소 엔진 `[1,26,60]`을 선언한다.

## 다음 재개 지점

1. 사용자가 `.mcaddon`을 시험 월드에 적용하고 [수동 시각 검수 절차](docs/MANUAL_VISUAL_QA.md)에 따라 상태창/직업, 1·3인칭 무기, 보스 외형·체력바·공격 예고, 보상 화면을 캡처한다.
2. 캡처를 기준으로 모델/리그/부착 위치/한국어 잘림/화면 조작을 판정하고 발견한 문제를 수정한다.
3. 게임 내에서 보스·아이템·레시피 및 재접속을 확인한 뒤, 두 실제 플레이어로 보상과 동시 전투를 검증한다. 완료 전까지 관련 상태를 `PASS`로 올리지 않는다.
4. 검증 후 다음 고우선순위는 클래스별 전투 밸런스와 던전 진입/보스 도전의 실제 플레이 테스트다.
