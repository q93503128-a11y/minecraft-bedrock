# GT RPG — 던전 입구 및 재사용 공간 설계

2026-11-24. 사용자가 제시한 핵심 변경: **입장 전 난이도 선택, 여러 던전, 클리어한 입구는 일회용, 패배하면 입구 유지**. 월드에는 입구만 자연 생성하고, 던전 종류별 서로 다른 전용 맵을 재사용하는 방향. 사용자 확정: 미로 최소화, RPG 전리품은 성공 시 지급, RPG 경험치는 처치 시 획득하고 실패해도 유지. 사용자 추가 요청: 솔로 기준은 도전적으로, 협동의 이점 유지. 입장 UI·임시 파티/관전은 직전 제안에 이어 채택 방향으로 기록하되 세부 수치는 검증 전 가안. 구현 미착수.

## 1. 구조
- 생존 월드에는 실제로 탐험할 수 있는 작은 입구 구조물(폐묘, 신전 입구, 얼음 동굴 입구, 네더 성채 입구)을 지역에 맞게 자연 생성. 기존 바닐라 구조물/월드 생존/채굴/건축 유지. 입구와 내부가 모두 실제 월드에 매번 생성되는 방식 대신 입장 시 전용 던전 공간으로 이동하는 방식 권장.
- 던전 종류마다 **서로 다른 전용 공간, 레이아웃, 건축 테마**를 사용한다. 같은 종류의 입구 여러 개만 동일 던전 템플릿을 재사용한다. 다른 종류의 던전에 하나의 맵을 색상만 바꾸어 공용하지 않는다. 각 입구는 차원+좌표+영구 고유 ID로 식별. 입구의 사용 여부는 세계 공용으로 저장(플레이어마다 다시 사용할 수 없는 방향). 성공 시 **입구 활성화 기능만 비활성화**, 구조물 자체는 폐허로 남기는 가안. 새 입구는 새로운 탐험/파밍 기회. 입구 파괴/재설치/복제/청크 재로딩으로 사용 횟수 초기화 불가.
- 이전에 제안한 최초 클리어 후 모험가의 서에서 무한 무료 보스 소환은 일회용 입구 규칙과 충돌하므로 현 설계에서는 채택하지 않는다. 강화 난도도 새로운 미사용 입구에서 바로 선택(이전 기본 난도 클리어 강제 없음). 별도 승급 도전은 기존 반복 가능 규칙 유지.

## 2. 던전 후보
기존 보스와 적을 재사용하여 아래 네 종류의 주요 던전을 우선 검토. 크기/방 수는 가안이며 추가 소형 던전은 이후 논의.
| 던전 | 입구 | 기본 미니보스 → 보스 | 방 구성 후보 |
| --- | --- | --- | --- |
| 지하 묘지 | 평원/숲의 묘지·석조 입구 | 데스 나이트 Lv.8 → 리치 Lv.10 | 복도, 묘실, 숨겨진 상자, 보스방 |
| 사막 신전 | 사막의 사암 입구 | 미노타우로스 Lv.17 → 거신 Lv.20 | 함정 통로, 전투실, 보물방, 보스방 |
| 얼음 동굴 | 설원/빙원 동굴 입구 | 아이스 골렘 Lv.32 → 얼음 마녀 Lv.35 | 빙굴, 갈림길, 상자방, 보스방 |
| 악마의 성채 | 네더의 현무암 입구 | 오우거 Lv.43 → 마왕 Lv.50 | 성채 통로, 전투실, 보물방, 보스방 |
- 주요 던전은 약 4~6개 의미 있는 방(입구/복도 제외 여부는 맵 설계 시 확정)으로 시작. 고정된 레이아웃을 우선 쓰고 적/상자 배치를 소수 후보 위치에서 변경해 반복감 완화. **미로 중심 설계 금지.** 주 진행로는 쉽게 알아볼 수 있는 선형 동선으로 구성하고, 짧은 선택형 보물방/숨겨진 방만 분기한다. 길 찾기, 반복 왕복, 막다른 길, 복잡한 퍼즐을 공략의 필수 조건으로 만들지 않는다. 각 던전의 방 크기·동선·지형·건축은 다르게 구성한다.
- 일반/정예 몬스터 기본 행동 유지, 미믹은 별도 위장 개체로 진짜 개인 보상 상자를 대체/삭제하지 않음. 보스방 진입/제단 상호작용으로 보스 전투 시작 후보. 던전 내부 블록 파괴/설치, 포탈, 외부 순간이동 등 악용 차단 및 정상 탈출 방법은 테스트 필요.

## 3. 입장 전 난이도
- 입구 상호작용 시 던전명, 기본/강화 난이도, 추천 레벨, 몬스터/보스 레벨, 보상 차이를 표시. 세계 위협도 W 이하의 정수 도전 위협도 d를 0~W에서 자유 선택. d=0은 기본 고정 레벨, d>0은 각 몬스터/보스 기본 Lv+3d(계수 가안). W=15일 때 d=10 선택 가능. d 및 W는 시작 시 확정하고 선택 범위를 서버에서 검증. W=0이면 d=0만 제공.
- 난이도는 해당 세션에만 적용. 다른 자연 몬스터/다른 파티/세계 위협도에 영향을 주지 않는다. 강화 성공 자체는 W 상승 아님. 강화 시 보상 레벨/XP 및 높은 희귀도·고유 장비 확률 상향, 확률 상한 유지.
- 별도 입장권/재료 소모 없음. 일반/강화 선택 모두 성공 시 해당 입구 소모. 실패 후 난이도 변경하여 재시도 가능.
- 입구 문/제단 상호작용으로 최소 UI를 열고 혼자 입장 또는 함께 입장 선택. 함께 입장은 임시 대기방 생성, 친구가 같은 입구에서 명시적으로 참가, 방장이 명단 확인 후 시작. 난이도 변경 시 참가자에게 다시 확인. 시작 직전 실제 참가자/입구/구역 상태 재검사. 월드 전체 동의는 승급 도전에만 필요. 강제 순간이동 및 상시 파티 가입 의무 없음.

## 4. 공간 재사용과 동시 입장
- 권장: 한 개의 던전 전용 커스텀 차원에 던전 종류별로 분리된 고정 전투 구역. 한 구역은 한 파티만 사용. 같은 종류의 여러 입구가 동일한 템플릿/구역을 참조할 수 있음. 다른 종류의 던전은 구역이 분리되어 있으면 동시에 이용 가능.
- 같은 종류 던전이 이미 진행 중이면 **입장 전 사용 중 안내**, 입구는 소모하지 않는다. 동시 이용이 필요해지면 기존 템플릿을 다른 빈 좌표에 복제하여 구역 풀을 확장. 처음부터 무한 인스턴스 생성하지 않음.
- 목표 Bedrock 버전에서 커스텀 차원 문제가 있으면 별도의 안전한 월드 내 공간 후보를 검토하되, 기존 유저 지형/건축/월드 데이터 덮어쓰지 않는다. 사용 중 아닌 구역은 엔티티를 유지할 필요 없음.
- 전용 구역 준비 완료 전 텔레포트하지 않는다. 구역 상태/입구 상태/플레이어 세션/원래 차원과 좌표를 저장하고, 리셋은 해당 구역에만 적용. 해당 세션 ID로 스폰된 몹·상자·잔류 투사체만 정리(다른 플레이어 소환수/월드 엔티티를 무조건 제거하지 않음). 세션 전환 시 소환 직업의 소유권/재소환/쿨타임 보존.

## 5. 입구 상태 및 승패
- 입구 미사용 → 사용 중(잠금) → 성공하면 클리어 완료(영구 소모), 실패/취소하면 미사용으로 복구. 사용 중에는 중복 입장 금지. 구역 준비 실패/빈 구역 없음/접속 종료만으로 소모 금지.
- 성공 조건 후보: 최종 보스 정상 처치. 참가자 개인별 기여 보상을 확정한 후 입구 소모를 같은 멱등 정산으로 기록. 숨겨진 방 전체 탐색 강제하지 않음. 보스 전투 전에 탐험/상자 수집 가능.
- 전멸/포기 시 입구 남고 초기화 후 재도전. 일부 사망 시 승급과 같이 관전하고 살아 있는 동료가 클리어하면 세션 성공, 입구 소모. 사망자는 재참전 금지, 기존 실제 기여 기반 개인 보상 자격 유지 방향. 사망 시 RPG 및 일반 인벤/장착 장비/XP 보존, 이미 사용한 소모품은 복원하지 않음. 사망 후 관전, 전멸/포기 시 미확정 보상만 폐기. 승급 관전 규칙은 변경 없음.
- 서버 종료/이탈: 세션 중단 또는 복구 시 성공이 기록되지 않았다면 입구 재사용 가능. 이미 성공/보상이 기록된 입구가 서버 재시작으로 재활성화되면 안 됨. 플레이어 복귀 실패 시 안전한 복귀 위치 저장/복구. 입구 사용 중 상태가 영원히 남지 않게 회수.
- 성공한 입구는 플레이어/파티가 달라도 재사용 불가. 같은 종류의 미사용 입구를 새로 찾아 반복 파밍할 수 있음. 입구별 영구 ID와 세션별 ID 구분.

## 6. 보상 정산 — 사용자 확정
- RPG 경험치는 일반/정예/미니보스/보스 처치에 실질적으로 기여한 플레이어에게 기존 XP 규칙대로 즉시 지급하며, 던전 실패·포기·재입장 이후에도 유지한다. 실패했다고 획득 XP를 회수하거나 클리어 시까지 잠그지 않는다. 재도전에서 정상적으로 다시 생성된 적을 처치해 얻는 XP도 허용. 단일 처치 이벤트 중복 지급과 무한 소환몹 보상 악용은 방지한다.
- 던전에서 획득한 RPG 장비, 보물상자 전리품, 각인서, 보스 고유 장비 등 아이템 보상은 세션 종료 전까지 임시 보상으로 기록. **최종 보스 처치로 클리어가 확정될 때 개인별 지급**. 실패/포기 시 임시 아이템 보상은 폐기하고 입구는 유지. 임시 보상을 장착/거래/사용/외부 반출해 실패 후 반복 파밍하는 것은 불가. UI에 획득 예정 보상임을 명확하게 표시한다. 사용자 승인: 개인별 세션 임시 보관소에 장비/각인서/상자 보상 등을 누적하고, 성공하면 RPG 가방으로 지급. 가방 만석/오프라인은 확정 보상 회수 대기 데이터로 보존, 실패하면 임시분만 폐기. 물리 상자가 아니라 서버 기록 방식 후보.
- 성공 시 입구 영구 소모와 보상 정산의 일관성을 유지한다. 가방 가득 참/접속 끊김에서도 확정 보상 영구 분실 및 두 번 지급 금지. 기존 야생 바닐라 XP/드롭 유지. 던전 내 정상 처치 바닐라 XP는 즉시 유지, 새로 획득하는 일반 아이템도 RPG 전리품처럼 임시 보관 후 성공 정산(위임에 따른 초기 정책).
- 고난도 고보상 유지. XP 파밍 효율은 실제 플레이 테스트에서 관찰하고 필요하면 적 레벨·수량·진행 시간을 조정하되, 실패해도 정상 획득 RPG XP가 유지된다는 사용자 규칙은 바꾸지 않는다.
- 입구 생성 빈도/이동 거리/던전 보상 효율은 실제 탐험 시간 기준 조정한다. 던전 사망/관전 및 보유 장비 보존 확정, 파티 탈퇴/보상 참여 조건의 구현 세부는 시험 후 조정.

## 8. 입장 대기 및 솔로 난도 (2026-11-24)
- 입구에서 직접 상호작용 → 난도 선택 → 혼자 시작/함께 입장. 함께 입장은 해당 입구의 임시 대기방, 친구는 같은 입구에서 참가/취소, 방장 시작. UI는 간결한 던전명·난도·레벨·보상 차이·참가자/직업/레벨. 다른 플레이어에게 UI를 강제로 열거나 지나가는 사람을 자동 참가시키지 않는다. 대기 취소/방장 이탈 시 잠금 회수. 시작 후 참가자 확정, 외부 신규 난입 금지, 기존 참가자 재접속 복귀 후보, 종료 시 자동 해산. 참가 거리/대기 제한 시간/최대 인원은 실기 검증 전 미정.
- **솔로는 적정 레벨·장비에서도 제법 어려워야 한다**. 패턴 회피, 적의 공격 구분, 장비와 스탯 선택이 중요. 다만 9개 직업 모두 솔로 가능, 힐러/탱커 필수화 금지. 단순 HP 뻥튀기보다 전투 배치/위험한 공격과 명확한 회피 기회, 공격 후 빈틈으로 난도 조정.
- 인원 보스 HP 배율 가안 1/1.75/2.5/3.25(1~4명), N 시작 시 참가자 기준 1+0.75(N-1). 공격력 인원 배율 없음. 기본 난도 및 강화 난도 모두 전용 던전 세션에서 동일 적용 후보. 기본 던전 레벨 고정은 유지. 죽거나 이탈해도 보스 HP 재계산 없음. 보상 분배 없음, 기여자 개인 보상. 기존 전투 수치에 중복 배율을 곱하지 않는다.
- 동일 수준 N명이 공격만 하는 단순 가정에서 파티 보스 TTK는 솔로 대비 1/0.875/0.833/0.8125배(회피/지원/공격 간격 미포함). 협동 유리의 방향을 확인하는 산술일 뿐 실기 DPS 아님. 파티원이 많다고 잡몹을 무한 추가하지 않는다.

## 9. 던전별 세부 콘텐츠 초안
전투 구역은 일반/정예 전투 구역만 센다(미니보스·최종 보스 제외). 각 던전은 전용 맵, 단일 주 진행로와 짧은 선택형 보물방. 방 배치·크기·몹 수/레벨/시간은 전부 검토용 가안. 기존 MONSTERS의 기본 미니보스/보스 레벨 유지. 아래 소요시간은 적정 레벨·장비 솔로의 탐험+전투 목표, 실측 아님.
| 던전 | 일반 전투 구역 | 선택 보물방 | 일반 몹 기본 레벨 | 일반 몹 총수 목표 | 소요시간 목표 |
| --- | ---: | ---: | --- | ---: | --- |
| 지하 묘지 | 3 | 1 | 5~8 | 12~16 | 5~8분 |
| 사막 신전 | 3 | 2 | 13~17 | 16~20 | 6~10분 |
| 얼음 동굴 | 4 | 2 | 24~32 | 18~24 | 8~12분 |
| 악마의 성채 | 4 | 2 | 38~43 | 22~28 | 10~15분 |
- 기존 4~6개 의미 있는 방 가안은 위 세부 구조로 구체화(입구, 복도, 선택방 및 전투 구역/보스방 계산은 분리). 한 구역에서 모든 적을 한꺼번에 스폰하지 않고 필요한 구역만 활성화. 좁은 통로의 무한 병목/소환수 고립 금지. 주요 통로 폭 4~6블록 이상 후보, 전투 구역은 충분한 회피 공간, 보스방 20~30블록급 이상 후보. 24기 군단/복수 소환사 실제 성능 및 이동 검증 후 조정. 수치만 맞추기 위한 사각형 동일 맵 금지.
- 지하 묘지: 석조 계단→묘실(좀비·스켈레톤·유령)→큰 관이 있는 방(데스 나이트)→묘실/짧은 옆방→리치의 방. 벽의 관/기둥으로 테마 형성.
- 사막 신전: 사암 통로→미라·전갈 전투→넓은 중정→미노타우로스→보물방 분기→거신의 석실. 간단한 압력판/화살 함정은 짧고 명확한 회피 가능 후보, 필수 퍼즐 없음.
- 얼음 동굴: 자연 동굴 형태→얼음 호숫가(스트레이 등)→아이스 골렘→넓은 수정/얼음 공간→얼음 마녀. 낙사/미끄러짐이 필수 피해가 되지 않게 통로 확보.
- 악마의 성채: 성문→성채 통로/중정(블레이즈·위더 스켈레톤·악마)→오우거→용암이 보이는 안전한 통로→마왕의 방. 소환군 이동에 좁은 용암 다리 강제하지 않음.
- 선택방에 미믹이나 일반/희귀 상자 후보 배치. 보물방 탐색이 클리어 필수 조건이 아님. 아이템 성공 정산/실패 XP 유지 및 입구 일회용 규칙 보존.

## 10. 입구 자연 생성 빈도 초안
- 던전이 핵심 파밍 콘텐츠이므로 입구는 희귀하지만 지나치게 드물면 안 된다. 주거지 바로 옆에 여러 입구가 겹치는 배치도 금지. 초기 목표: 적합한 바이옴에서 묘지 250~450블록, 사막 신전 350~600, 얼음 동굴 400~700, 네더 성채 350~600블록 수준의 체감 발견 간격. **정확한 최소거리/확률 보장이 아니라 탐험 검수 목표**. 바이옴 크기·지형·시드별 차이 고려.
- 공식 [Feature rules](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/featurerulesreference/examples/featurerulescomponents/feature_rules_document?view=minecraft-bedrock-stable), [Introduction to Features](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/featuresreference/examples/featuresintroduction), [Structure template feature](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/featuresreference/examples/features/minecraft_structure_template_feature?view=minecraft-bedrock-stable)로 바이옴·배치 조건/분포 설정 가능. 독립 청크 확률만으로 최소 간격 보장한다고 가정하지 않는다. 생성 후보 간격/충돌 방지 기술 검증 후 실제 확률 확정.
- 입구는 발견 가능한 지표/동굴 입구 형태, 땅 속에 완전히 매몰되거나 물/용암 위에 뜨지 않도록 실제 생성 조건 검증. 기존 생성 청크에 무단 구조물 덮어쓰기 금지. 신규 청크 탐험 기준.
- 참고: [The road to Dungeons](https://www.minecraft.net/de-de/article/the-road-dungeons)의 알아보기 쉬운 랜드마크와 구간별 레벨 구성, [Abyssal Monument](https://www.minecraft.net/de-de/article/abyssal-monument)의 테마에 맞는 공간/기믹 차별화. GT RPG는 과도한 미로/수중 산소 강제 등을 채택하지 않고 직관적 주 진행로를 유지. 공개 개발 설명 확인, 실제 플레이 영상 검토/맵 제작은 NOT_RUN.
- 최소 5개 시드의 대표 바이옴 생성률/입구 간 거리/충돌/발견 시간, 1~4인 솔로·파티 클리어 시간·생존률·XP/아이템 효율 시험 후 조정. 구현 승인 전 코드/맵/에셋 생성 없음.

## 11. 던전 보상 세부 가안
기존 사용자 확정: 경험치는 실제 처치 기여 시 즉시 지급, 실패해도 유지. 아이템 보상은 성공 시 지급, 실패/포기 시 폐기. 새로 제안하는 아래 확률과 수량은 사용자 검토용 밸런스 초안이며 확정 실측값 아님.

| 획득처 | 장비 1개 드롭 시도 성공률 | 각인서 1개 독립 드롭률 |
| --- | ---: | ---: |
| 일반 몬스터 | 12% | 1% |
| 정예 몬스터 | 65% | 10% |
| 일반 상자 | 100% | 10% |
| 희귀 상자 | 100% | 40% |
| 미니보스 | 100% | 20% |
| 최종 보스 | 100% | 50% |

- 각 확률은 실질 기여자별 독립 시도이며 일반 장비와 각인서가 동시에 나올 수 있다. 일반/희귀 상자는 주 진행로에 기본 1개, 선택 보물방마다 1개 가안(상자 종류의 희귀 확률 초기 30%). 직접 발견한 상자 보상 자격은 참가자별 회수 기록과 전투 기여 확인을 함께 검토. 상자 개봉 시 세션 임시 보상 등록. 보스 고유 장비는 일반 장비 1개 드롭과 별도로 추가 시도한다.
- 각인 종류는 EQUIPMENT의 각인 풀, 장비 유형은 해당 적/던전 가중치. 무기/방어구/장신구 모두 획득 가능. 해당 클래스 제한 없음. 별도 필수 골드/강화 재화 도입하지 않음.
- 기본 난도 및 강화 난도의 조건부 희귀도 분포(일반/고급/희귀/영웅/전설 순서, 합 100%):
| 출처 | 기본 난도 (%) | 도전 위협도 d>=20 (%) |
| --- | --- | --- |
| 일반 몹 | 65 / 27 / 7 / 0.9 / 0.1 | 55 / 27 / 12 / 5.5 / 0.5 |
| 정예 | 15 / 45 / 30 / 9 / 1 | 10 / 35 / 35 / 17 / 3 |
| 일반 상자 | 40 / 40 / 17 / 2.5 / 0.5 | 30 / 35 / 25 / 8 / 2 |
| 희귀 상자 | 0 / 20 / 55 / 22 / 3 | 0 / 10 / 50 / 32 / 8 |
| 미니보스 | 0 / 25 / 50 / 22 / 3 | 0 / 15 / 45 / 32 / 8 |
| 최종 보스 | 0 / 10 / 45 / 35 / 10 | 0 / 5 / 35 / 40 / 20 |

- d=0에서는 W가 높아도 기본 분포. d>0에서는 t=min(d/20,1)로 두 분포 사이 선형 보간, 장비 레벨은 실제 적/상자 기준 레벨+3d(기존 가안). d=20 이후 확률만 상한, 레벨/XP 성장 상한 없음. 장비 드롭률/각인서 드롭률 자체는 초기에는 동일하게 유지. 보스 고유 장비 추가 드롭률 기본 20%, 강화 20%+20%×t. 해당 보스 고유 장비 풀에서 1개 선택, 희귀도는 해당 난도 보스 분포로 별도 추첨. 고유 효과 자체는 고정. 기존 보유 장비 레벨 변화 없음.
- 평균 장비량 산술: 일반 적 12~28기만 있다고 가정, 미니보스/보스 1개씩, 주 상자1개+선택방 1~2개 전부 회수, 고유 추가 0.2~0.4개 기대값이면 5.64~8.76개 수준. 정예 추가/미탐색/기여 여부에 따라 변동. 초기 목표 대략 5~9개, 확정 보장 수량 아님. 일반 12%는 MONSTERS 기존 가안 유지. 보스/미니보스 장비 1개는 해당 전투 실질 기여자 기준.
- XP는 BALANCE 기존 곡선 그대로. 예시 지하 묘지 일반 Lv.7 14기, 미니보스 Lv.8 1기, 리치 Lv.10 1기라면 기여자 XP=14×44+7×48+12×56=1624, Lv.10의 단일 레벨 필요 XP(365)의 약 4.45배. 실제 연속 레벨업 요구량은 증가하므로 4.45레벨 상승을 뜻하지 않음. 현재 성장 속도가 빠를 수 있음; 실제 던전 클리어/반복 실패 XP 효율을 관찰해 총 XP 곡선/몹 수를 튜닝하되 실패 XP 보존은 변경하지 않는다.
- 상자 보상 표시/정산은 한 번만 기록, 보스 소환 몹 보상 반복 악용 차단. 가방 만석 시 이미 확정된 개인 보상을 유실시키지 않을 회수 대기 방식 후보. 직접 월드 아이템으로 무한 떨구지 않음.
- 참고 [Minecraft Dungeons September Update](https://www.minecraft.net/en-us/article/dungeons-september-dev-blog) 고난도 임무의 희귀/고유 장비 보상, [Diablo III Greater Rifts](https://news.blizzard.com/en-us/article/15317478/patch-2-1-0-preview-greater-rifts) 최종 수호자 보상, [Adjusting the Endgame](https://www.minecraft.net/en-us/article/dungeons-dev-blog---adjusting-endgame) 난도 개방/희귀 보상. GT RPG는 입장권/시간제한/순위표 미채택, 실패 경험치 유지. 공개 공식 설명 검토, 영상/직접 플레이/밸런스 실측 NOT_RUN.

## S5 회복 포션 후보 연계
SYSTEMS 8.1의 RPG 회복 포션 신규 도입 제안은 검토용. 기존 소지 포션 사용 가능, 던전 내 새로 얻은 포션은 임시 보상에 포함하여 성공 시 정산, 실패 시 폐기 및 소비분 미복원 원칙 유지. 기존 장비·각인서 드롭률 변경 없음.
