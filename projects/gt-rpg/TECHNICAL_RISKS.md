## 2. 커스텀 활 / 투사체 / 스탯
- RPG 활: `minecraft:shooter`, `minecraft:use_modifiers` 등 커스텀 활 지원 사례가 있으나 **팩 포맷/실제 렌더·충전·애니메이션/화살 인챈트 작동 확인 전**.
- 바닐라 '빠른 장전'은 기본적으로 **쇠뇌 인챈트**. 궁수 은신 시 활 당기는 속도 버프는 사용자 결정으로 **삭제**. 기본 RPG 활별 충전시간 차별화는 검토할 수 있음.
- ATK 공통 스탯이 RPG 화살 피해/마법 공격에 적절히 반영되도록 피해 계산 소스 권위 정의. 바닐라 화살 기본 공격·인챈트·스크립트 추가 피해 중복, 피격 무적 시간, 활 위력/헤드샷 여부, 맞지 않은 화살의 데미지 지우기 등을 테스트.
- 궁수 6차 5번째 사격 확정 3효과, 4발 각 100%, 도탄 중복 타격/무한 재발사 방지; 화살 발사자·소유자·원본 사격 ID 추적 필수.
- 마법사 지팡이 없을 때 마력 공격·패시브의 발동 방식과 도구/검 우클릭 스킬 충돌 해결 필요.

## 3. 소환수와 상태 보존
- 한 주인의 골렘 **최대 1기**, 드루이드 늑대 1+사슴 1, 네크로맨서 6차 약 24기 및 이후 확장.
- 식별자: 소유 플레이어, 직업, 소환 타입, 세션/월드, 스폰 시각/소멸·재소환 의도. 같은 플레이어의 중복 로그인, 청크 언로드, 차원 변경, 세이브/재시작, 사망/직업 전환 정리.
- 네크로맨서 사체 부활: 사망 이벤트에서 사망 위치/기여 소유자/부활 가능 원본 타입 확인. **보스·플레이어·아군·소환수 죽음을 재료로 허용하면 안 됨.** 기존 전리품/XP 훼손하지 않기. 동일 사망 이벤트 중복 처리 방지.
- 군단 AI 공유 목표, 상태 갱신 주기 제한. 모바일 실기 + BDS에서 1~N명 동시 직업·여러 군단·좁은 동굴·차원 이동 중 TPS/프레임/메모리 측정.
- 다른 플레이어가 네크로맨서와 골렘술사로 싸울 때 우호/적대 판정 및 콜로세움 격리 필요.

## 4. 던전 / 승급 / 관전
- 일반 월드 생성 구조물은 `.mcstructure`·feature rule·jigsaw 등 후보. 기존 생성 청크, 던전 상자 개인 기록, 월드 블록 보호, 중복 구조물 경계 확인.
- 별도 전투 공간은 JSON 정의 커스텀 차원(이전 대화에 **Bedrock 1.26.50부터 지원** 주장), 또는 주 월드 내 격리 구조물 후보. 차원 생성 지원과 **파티별 자동 인스턴스 제공은 별개**. 공식 최신 문서 및 Android/BDS 실기 검증 전 확정 금지.
- 승급 투표는 현재 온라인 구성원 기준 전원 동의 및 전원 참가, 거절/타임아웃/이탈 처리. 레이스: 투표 발의 중 접속자 변경, 투표 완료 직전 이탈, 중복 도전, 재시작·결투와 동시 참가.
- 승급 단계의 위협도 갱신은 **수호자 최종 처치에 따른 단일 성공 판정 후 단 한 번** 커밋. 중복 지급·실패 후 상승·0 이하/정수 오버플로 방지.
- 관전은 사망 후 리스폰 시 `GameMode.Spectator` 전환 후보. **관전자가 동료 시점을 직접 공유할 수 있는지는 별도**. 성공/전멸/접속 끊김/월드 재시작 시 게임모드·인벤·좌표 안전 복구 필요. 스폰 지점·기존 게임모드 기록.
- PvP 콜로세움은 승인한 당사자·소환수만 서로 적대. PvP off와 이벤트 피해 차단, 광역 피해/투사체/환경 피해/결투 중 방해, 경기 중 이탈/탈주 모두 검증.

## 5. RPG 보관함 / 장비 저장
- 기본 인벤 36칸 직접 확장보다 별도 RPG 가방(카테고리별 54칸, 총 216칸 최신 가안). 각 장비는 **고유 식별자, 타입, 장비 레벨, 희귀도, 랜덤 옵션, 각인, 고유 효과**가 저장·복원되도록 설계.
- 개인별 상자 중복 획득 방지: 월드+구조물+상자+플레이어 ID 기준 획득 이력, 보상 생성과 인벤 수령 트랜잭션 처리, 가방 가득 참/리로그/서버 재시작/중복 클릭 고려.
- 기본 아이템 클래스와 커스텀 아이템 컴포넌트 인챈트·내구도 동작을 분리. RPG 장비는 내구도 없고 **각인**은 커스텀 스크립트 효과. 바닐라 아이템/제작법 원상 유지.
