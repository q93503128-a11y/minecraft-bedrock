## 감사 범위
저장소 루트 README/AGENTS/BUILD_STANDARD/QUALITY_STANDARD 및 프로젝트 인덱스, dev-playbook README/global/development 규칙, 프로젝트 문서들을 확인. 디렉터리 실제 파일 15개 모두 문서이며 BP/RP/모델/실행 패키지 없음. 문서 핵심 불변조건 및 표본 충돌 점검이며 모든 스킬 계수/외부 링크 전수검증은 아님. 모든 엔진/모바일/멀티 시험 NOT_RUN.
## 충돌·누락·미결정
| 항목 | 관찰 및 조치 |
| --- | --- |
| 기본 RPG 무기, 가방 | 첫 직업 선택 시 플레이어당 1회 Lv.1 일반 기본 무기 지급. 보유 RPG 장비/가방 사망 보존으로 결정. |

| 던전 | 최신 d=0~W 선택, 레벨+3d 및 d20 확률 상한. W는 선택 상한. 일부 남은 표현 정리, 과거 변경 이력 유지 |
| PvP | 기권 및 종료 후 결투 직전 상태 복원 확정. 경기용 별도 상태와 외부 스냅샷 격리. 기술 검증 필요. |
| HUD | 최신 HUD_DESIGN 5절의 HP바 위 금색 흡수/아래 청색 보호막 우선. 실제 흡수 잔여량·엔진 HP 연동 미검증 |
| 사망 | 보유 RPG 장비·가방·성장 보존, 야생 바닐라 규칙 유지. 던전/승급 일반 인벤도 보존, 소비분 복원 없음. PvP 직전 상태 복구. |
| 밸런스 | DPS 목표는 참고만, 성장 체감·개성·상성·실제 문제 중심. XP 성장/소환/공속·범위 실기 검증. 확정 메커니즘 임의 축소 금지. |
| 협동 | 기여자 전량 XP, 유효 회복/보호/버프의 기여 수치·시간창 미정 |
| 월드 | 초심자 보호 범위·입구 생성 간격 실기 확인, 기존 월드 덮어쓰기 금지 |
| 외부 근거 | 기존 공식 문서/공개 설명 링크 최신성 및 정확성 재검증 필요. 직접 영상/설치/라이선스 검증과 구분 |

대표 직업과 단계는 가안. 구현 승인 전 BP/RP/코드/에셋 생성 금지. 각 단계 SOURCE_ONLY/STATIC_PASS/PACKAGE_PASS/ENGINE_PASS/MULTIPLAYER_PASS 및 NOT_RUN/BLOCKED 구분. 사용자 직접 플레이 검증 존중. 외부 실제 게임/Bedrock 사례 및 합법적 원본 확보, 임의 코드 디자인으로 최종 품질 대체 금지. 실패 경로·권위·소유권·수명·보상 멱등성 우선. 공통 플레이북은 수정하지 않음.
