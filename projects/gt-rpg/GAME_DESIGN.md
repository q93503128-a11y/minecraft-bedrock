# GT RPG — 전체 게임 기획 정본

기준: 2026-11-24까지의 **이 프로젝트 사용자 대화에서 합의된 설계**. 실제 Bedrock 런타임에서 검증했다는 뜻이 아니다. `확정`은 게임의 의도, `가안`은 숫자·방법·참고예시다.

## 1. 핵심 플레이 루프
바닐라 생존(채굴/건축/농사/탐험/기존 제작) → 일반/정예 몬스터 사냥 → 직업 레벨업과 스탯 배분 → 장비 및 던전 상자 파밍 → 전직 → 보스·고정 난이도 던전 → **전원 동의** 승급 도전으로 세계 위협도 +1 → 성장한 야생·정예 몬스터와 추가 파밍 → 반복. 별도 퀘스트·전직 재료·의무 경제 노가다는 두지 않는다.

## 2. 플레이어 성장 (확정)
- 기본 직업: **전사, 궁수, 마법사, 암살자, 성기사, 드루이드, 골렘술사, 네크로맨서, 사제** 총 9개. 서로 다른 직업으로 파생하는 전직은 없음.
- 직업별 레벨 상한 **없음**. 기본 사냥으로 경험치 획득. 다음 레벨에 필요한 XP는 레벨에 따라 증가하고 적의 레벨이 높을수록 획득 XP도 증가. 구체 공식은 [BALANCE.md](BALANCE.md)에 가안으로 마련했으며 실기 검증·사용자 수정 전 확정하지 않는다; 기하급수적 부담을 피한다.
- 레벨업 때 **직업별 가중치에 따라 자동 기본 능력치 증가 + 자유 배분 스탯 포인트 3개**.
- 배분 스탯 **ATK(공격력), DEF(방어력), HP(체력), SKL(기술력)**만 유지. 기본 공격은 주로 ATK, 기술력은 스킬의 최종 효과 배율에 영향을 줌(공격·치유·소환 공통). 별도의 원거리 공격력은 만들지 않는다.
- 공격/방어/체력/기술력 계수는 직업·기술마다 다르게 설계한다. 특히 **회복 기술의 HP 계수는 받는 사람 아닌 시전자 자신의 최대 HP 기준**. 예: (기본 회복 + 시전자 최대 HP × HP 계수) × SKL 배율, 실제 회복은 대상의 잃은 HP를 초과할 수 없음. 고정 20% 같은 숫자는 미확정 가안.
- 전직 조건: 1차 Lv.1, 2차 Lv.10, 3차 Lv.20, 4차 Lv.30, 5차 Lv.40, 6차 Lv.50. 레벨만 충족하면 **플레이어가 메뉴의 전직 버튼을 직접 눌러 진행**; 자동 전직 아님, 재료/퀘스트 없음, 늦게 눌러도 가능.
- 전직마다 **새 패시브 1종 + 기존 액티브/패시브 1~2개 강화 + 직업별 소량의 영구 기본 능력치 상승**. 6차 이후에도 레벨 성장 지속.
- 각 직업 기본 액티브 **1개**로 조작 최소화; 직업 능력은 자동 발동 패시브 중심. 전직한다고 새 액티브 버튼이 쌓이지 않는다.
- **스탯 초기화는 언제나 무료**; 누적 배분 포인트 돌려받아 재배분.
- 직업 변경 가능. **직업별 레벨·XP·투자 포인트·전직 단계·스킬 성장을 독립 저장**. 처음 선택한 직업은 Lv.1부터 시작하고, 과거 직업으로 돌아오면 이전 성장 기록을 복구. 현재 직업만 경험치 획득. 가방·장비는 공용, 이전 직업 소환수는 정리.
- 경험치 공유: 적 처치에 실질적으로 기여한 플레이어(직접 공격, 소환수 공격, 치유, 보호막, 버프 등)에게 **각자 온전한 기여 경험치**를 제공; 마지막 타격 독점 없음. 근처에서 아무 기여도 없는 사람은 보상하지 않는다. 기여 판정 시간창/중복/오남용 대응은 기술 설계 필요.

## 3. 무기·스킬·전투
- **모든 직업이 모든 바닐라/RPG 장비를 사용할 수 있으며 무기 착용 제한은 없음.** 전사가 지팡이를 들거나 마법사가 검을 들어도 **직업 액티브를 사용 가능해야 한다**는 기능 요구. 구현 입력 방식은 별도 검증.
- 직업별 선호 장비는 옵션/스탯 시너지로 차별화. **ATK 하나**가 검·활·지팡이 장비 공격력과 물리/원거리 계산에 적용됨. 마법·치유·소환은 관련 계수와 SKL 배율 반영. 바닐라 공격 및 화살 기본 피해와 RPG 추가 피해의 중복/무적 프레임 문제 검증 필수.
- 기본 마법사 공격은 전용 지팡이에서 마력탄 발사 방향. **지팡이 미보유 시에도 마법사의 기본 공격/패시브 사용이 막히면 안 됨**; 대체 발동 경로는 미결정.
- **직업 액티브 입력 목표:** 주손 무기를 든 채 발동. PC에서는 전용 검·지팡이 우클릭/사용, 궁수는 활을 든 채 좌클릭/공격 버튼으로 은신을 제안. 베드락 모바일 터치, 바닐라 검의 허공 사용 이벤트, 활의 우클릭 사격 중복 등 **검증 전 구현 확정 아님**. 웅크리기 두 번 방식은 사용자 거절. 추가 HUD 버튼은 공식 안정 API에 한계; 기본안 아님. 필요 시 무기를 바꾸는 보조 스킬 아이템은 기술적 차선책.
- 스킬·패시브는 최소한의 시각 효과. 파티클 도배 금지, 피격 타이밍·사운드·외형·짧은 핵심 연출 중심, 시야 방해와 멀티플레이 성능 저하 회피.

## 4. RPG 장비·전리품·각인
- 바닐라 모든 제작법과 장비 사용 유지. 바닐라 무기도 유효하나 RPG 전용 장비가 높은 레벨의 전투에서 더 유리.
- RPG 장비: 검/대검/활/지팡이/방어구/장신구 등, 장비 레벨·희귀도·능력치 옵션·(있을 경우) 고유 효과. 희귀도에 따라 기본 능력치뿐 아니라 추가 옵션 개수도 증가(일반0~전설4 가안, [SKILL_BALANCE.md](SKILL_BALANCE.md)). 등급 **일반 → 고급 → 희귀 → 영웅 → 전설**.
- **장비 레벨은 떨어뜨린 몬스터의 레벨을 기준으로 결정, 획득 시 고정**, 위협도나 플레이어 레벨 변화에 따라 자동 증가하지 않음. 정상 장비도 레벨이 높으면 저레벨 전설/보스 장비보다 순수 능력치가 좋을 수 있음.
- 보스 특수장비는 독특한 모델·텍스처·아이콘과 고유 전투 효과로 차별화. **보스 장비가 항상 최강인 건 아님**. 신규 RPG 무기를 단순히 바닐라 무기 이름/스탯만 바꾼 형태로 끝내지 않는다.
- RPG 장비는 **내구도 없음**(부서지지 않음); 바닐라 장비는 원래 내구도·제작·인챈트 유지.
- **별도 신규 바닐라 인챈트 목록 제작 대신 RPG 전용 '각인' 시스템 추가**. 바닐라 장비는 기존 인챈트, RPG 장비는 레벨·옵션·고유 효과+각인 중심. 초기 장비당 각인 **1개**, 미래 2개 확장은 추후. 공격/회복/소환/방어의 *전투 행동을 바꾸는* 효과 선호. 장비 각인 부여·변경에 필요한 재료/확률은 미정.
- RPG 활도 필수 콘텐츠. 3D 모델/당기기 연출/일반 화살과 호환 목표, 장비 레벨·등급·각인 적용; 활마다 기본 충전 시간은 다를 수 있음(실제 베드락 확인 필요). **추가 원거리 공격력 스탯은 없음.**
- 바닐라 활·쇠뇌와 RPG 활 모두 궁수 능력 발동 목표. 바닐라 '빠른 장전'은 **쇠뇌 전용**, 활을 빠르게 당기도록 직접 적용할 수 없음. 궁수 은신 액티브의 당기기/공속 버프는 제거(직전 설계에 반영됨).

## 5. RPG 인벤토리·메뉴
- RPG HUD: 고정 길이 체력/최대 HP·보호막·배고픔·직업 XP/레벨·액티브 CD, 필요 시 적/보스 상태 표시. 바닐라 XP와 생존 조작은 유지. [HUD_DESIGN.md](HUD_DESIGN.md)의 기능 명세 및 기술 후보 참조.
- 바닐라 플레이어 인벤토리 36칸 그대로 유지(핫바 9 포함); Script API로 기본 칸 수를 직접 늘리는 방식이 아니라 **'모험가의 서'로 여는 RPG 가방/보관함** 추가.
- RPG 가방 초기 **총 54칸 가안**, **무기 / 방어구 / 장신구 / 재료 카테고리**별 자동 분류·필터 및 등급/레벨/능력치 정렬. 개별 아이템의 레벨/희귀도/옵션/각인/고유효과를 보존해야 함. 바닐라 인벤 ↔ RPG 가방 이동 지원.
- 메뉴는 **모험가의 서(소모되지 않는 전용 아이템)** 하나로 상태창, 장비, 가방, 스탯 배분·무료 초기화, 직업 전환·전직 버튼, 위협도·승급 투표, PvP 신청 접근. 분실 시 재발급 경로 제공.
- 바닐라 아이템 자동으로 모두 가방으로 옮기지 않음; 던전/보스의 개인 RPG 보상은 가방 직접 지급 우선 검토. 54칸 초과·중복 보상·저장 실패·인챈트 데이터 복원은 반드시 설계/시험.
- UI는 외부 실제 RPG/Bedrock 화면을 참고해 모바일에서 텍스트/터치 표준을 검수해야 함. 임시 폼/사각형 단순 나열을 최종 디자인으로 승인하지 않음.

## 6. 몬스터·보스·월드
- 바닐라 일반 적은 레벨·HP·ATK·DEF 조정, 장비 드롭·XP 레벨 연동. 정예 바닐라 변종과 고유 모델·패턴을 가진 신규 적을 함께 포함.
- 콘텐츠 구성 방향 **기존 바닐라 강화 약 60% / 신규 몬스터 약 40%**; **자연 스폰율 60:40을 뜻하지 않음**. 초안 12종 신규 일반·6종 정예/미니보스·4종 대형 보스는 **양산 할당량이 아닌 초기 규모 가안**.
- 일부 신규 적/보스는 지역별 등장, 구별되는 공격·드롭과 모델을 갖춤. 보스는 식별 가능한 패턴 2~3개와 예고/피격 정합성을 목표로 함. 유저가 아직 개별 보스 이름/패턴을 최종 승인한 것은 아님.
- 야생 일반 몬스터는 세계 위협도에 비례해 점차 성장하되 **시작 지점/초심자 구역은 낮은 난도** 유지해 신규 접속자가 생존 가능. 위험 지역은 추가 난이도.
- **특수 지역/일반 고정 던전/고유 이름 보스는 정해진 고정 레벨**로 위협도에 따라 무한 상승하지 않음. 반복형 승급 수호자는 도전 위협도에 따라 스탯이 상승하는 예외.
- 정예 야생 출현율은 위협도가 올라가며 **약하게** 상승하되 특정 위협도에 **상한** 도달 후 더 증가하지 않음. 예시: 위협 0=1%, 5=2%, 10=3%, 15=4%, 20부터 5% 상한. **정확한 수치 미확정**, 정예 도배 금지.

## 7. 무한 세계 위협도와 승급 도전
- **세계 공용 위협도는 0부터 시작, 상한 없음**. 실제 시간 흐름으로 자동 증가하지 않음.
- 위협도 +1의 조건은 반복 가능한 **승급 도전 성공**. 접속 중 **전원 동의**해야 시작; 한 명 거절·무응답/시간초과 시 시작 취소. 투표 중 이탈·재접속·동시 승인·늦게 온 플레이어 처리 정책은 기술적으로 확정 필요.
- 매 단계 도전에서 **기존 야생 일반/정예 몬스터 재활용**해 위협도에 맞게 레벨과 스탯을 조절. **1~3 웨이브 가안 + 마지막 승급 수호자**. 도전 단계마다 새로운 일반 몬스터를 무조건 제작하지 않는다.
- **승급 수호자의 공격 패턴은 위협도와 무관하게 동일**, HP/ATK/DEF 등 체급만 상승. 무한한 위협도 상승을 적 수 무한 증가나 패턴 추가로 해결하지 않는다. 웨이브당 몹 수·정예 비중에 상한.
- 성공 시 위협도 +1, 실패 시 그대로.
- **승급 도전에서 사망하면 관전자 모드로 대기**. 살아 있는 파티원이 승리하거나 모두 죽어 도전이 끝날 때까지 재참전 불가. 일부만 죽었으면 전투 진행, 전멸하면 실패. 종료 시 살아 있었든 관전했든 게임 모드/위치를 안전하게 복구.
- 위협도에 따른 야생 레벨·XP/전리품 레벨 상승은 지속하되 수치 폭주·정수 오버플로·초심자 진입불가 예방. 증가 공식 가안(위협도당 +3레벨 등)은 테스트 전까지 채택하지 않는다.

## 8. 던전·보상
- **일반 탐험 던전:** 자연 생성 구조물, 정해진 난도·몬스터·함정·미니보스·보스. 월드 탐험과 연결; 자연 생성된 기존 청크 처리, 상자 파괴/도난 대응 검토.
- **반복형 특수 던전/승급 도전:** 가능하면 격리 전투 공간에 들어가 웨이브/보스/보상/정리. 커스텀 차원·멀리 분리된 구조물 등 베드락에서 안정적인 구조는 미검증(기술 문서 참조).
- **Minecraft Dungeons식 상자 탐험 재미**: 일반 상자(골드/재료/일반~희귀 장비), 희귀 상자(희귀 장비/재료), 보스 보상(경험치/고레벨 장비/확률적 고유 장비). 골드는 예시 보상이지 별도 필수 경제·상점 확정 아님.
- **각 플레이어 별 독립 전리품**, 동료가 먼저 상자를 열어도 내 보상 사라지지 않음. 개인별 보상 회수 기록·반복 지급 방지 필수.
- 장비 레벨은 던전 자체의 고정 난도/해당 몬스터 레벨 기준. 특수 던전은 반복 파밍 가능, 진행할 때마다 전투 상태 초기화; 전체 세계나 타 플레이어의 던전 데이터를 무조건 삭제하지 않는다.

## 9. 협동·사망·PvP
- 복잡한 파티 가입 의무화 없이 함께 싸우면 협동 판정. 아군 회복·버프·보호·소환수 기여 및 개인 보상 적용. 소환수가 주인/아군/무관한 플레이어를 공격하지 않음.
- 일반 야생 사망은 바닐라 기본 규칙을 따름(인벤 드롭 여부는 월드 규칙), **RPG 레벨/직업/스탯은 영구 보존**. 반복형 던전 사망/관전 규칙은 승급과 동일한지 별도 결정.
- **야생에서 일반 PvP 금지.** 콜로세움 결투는 한 플레이어가 신청하고 상대가 **수락했을 때만** 별도 경기장에서 시작. 전투 전 체력 복구, 패배 판정 후 양쪽 복구·복귀. **아이템·장비·XP·레벨 등 손실 전혀 없음**.
- 콜로세움은 스킬/소환수까지 팀·대상 분리, 영역 탈출/이탈/재접속/동시 결투·무승부 처리 필요.

## 10. 아트/성능/콘텐츠 원칙
- 과도한 파티클 대신 모델 실루엣, 실제 움직임, 타격 판정, 짧은 사운드, 충격파 등 의미 있는 피드백 우선.
- 네크로맨서 후반 **20~30기 군단은 콘텐츠 목표**. 단순히 성능이 걱정된다는 이유로 목표를 5기로 임의 축소하지 않되, 모바일 최악 조건·동시 네크로맨서·BDS TPS 계측으로 최적화와 부하 예산을 정한다.
- 플레이어에게는 개발 내부 명칭/로그/테스트 상태를 노출하지 않는다. 유료 외부 자산/라이선스 불명 자산 무단 복사 금지.
- 복잡한 퀘스트·화폐·스킬 트리·대규모 신규 조작·추가 생존 제한은 **현재 기획에 없음**. 기본 시스템의 완성도를 우선.
