# 수동 시각 검수 요청

AI는 실제 게임 창을 조작하지 않았다. 아래 절차는 사용자가 직접 수행하고 스크린샷을 보내 주어야 하는 필수 확인이다. 월드 복사본에 팩을 설치하고, 친구가 함께 접속하는 화면에는 플레이어 이름·채팅 등 민감한 내용이 나오지 않게 가려도 된다.

## 캡처 방법

1. `.mcaddon`을 가져온 뒤 새 시험 월드에서 BP와 RP를 활성화한다. `/gtrpg:menu`를 입력해 첫 화면과 **모험가 기록**, **직업 선택** 화면을 각각 연다.
2. 직업을 고른 뒤 `/gtrpg:skill`을 한 번 사용하고, 대검을 장착해 1인칭 손에 든 모습과 친구 시점의 3인칭 모습을 캡처한다. 각 캡처에는 무기 전체와 팔 위치가 보이게 한다.
3. 평평한 장소에서 메뉴 → **보스 도전**으로 균열을 연다. 전갈 여왕 전체 외형, 이름/보스 체력바, 이동 중 다리·꼬리, 근거리 공격·피격 순간을 각각 찍는다.
4. 보스가 꼬리를 겨누거나 휘두르기 전 붉은 입자 예고가 나타나는 장면과 공격 직후를 짧은 영상 또는 연속 스크린샷으로 남긴다. 두 명 이상이 맞거나 피하는 장면을 함께 촬영한다.
5. 보스 처치 직후 각자의 인벤토리에서 잿불 조각/대검 이름과 아이콘을 찍는다. 인벤토리가 가득한 경우 보상 보류와 빈 슬롯 확보 후 수령 화면도 찍는다.
6. 같은 메뉴를 작은 창/가장 큰 GUI Scale, 모바일(가능하면 터치)에서 열고 한국어가 잘리거나 버튼이 눌리지 않는지 캡처한다. 멀티플레이 확인은 두 클라이언트에서 서로 다른 직업/레벨과 개인 보상 인벤토리를 함께 확인한다.

## 판정할 내용

모델 실루엣·크기·텍스처, 리그 관절과 이동/공격 동작, 1/3인칭 무기 부착, 보스 경고와 판정 동기화, 효과와 소리, 체력바, 한국어 줄바꿈, 화면별 버튼 조작, 개인 보상 중복 여부를 캡처 기준으로 확인한다. 어떤 화면도 자료가 오기 전에는 검수 완료라고 표시하지 않는다.
