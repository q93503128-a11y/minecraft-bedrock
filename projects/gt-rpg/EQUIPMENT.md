# GT RPG — 장비 및 각인 콘텐츠 기획 초안

2026-11-24. 사용자 검토 전 신규 제안이며 수치와 세부 종류는 가안. 기존 GAME_DESIGN/BALANCE/SKILL_BALANCE의 확정 메커니즘 유지. 구현 미착수.

## 1. 핵심 구조
장비는 유형/레벨/희귀도/기본 스탯/랜덤 추가 옵션/보스 고유 효과(해당 장비만)/각인으로 구분한다. RPG 장비는 내구도 없음, 바닐라 제작·인챈트·수선은 원래대로. 모든 직업이 모든 장비를 착용 가능; 무기 타입에 따라 직업 패시브의 실제 발동 조건만 달라진다. 직업 액티브는 어떤 장비로도 사용 가능해야 함. 장비 레벨은 획득 시 고정, 낮은 전설보다 높은 일반이 강할 수 있음. 높은 희귀도는 기본 스탯뿐 아니라 옵션 수로 매력 부여.

| 희귀도 | 기본 스탯 배율 | 추가 옵션 |
| --- | ---: | ---: |
| 일반 | 1.00 | 0 |
| 고급 | 1.10 | 1 |
| 희귀 | 1.22 | 2 |
| 영웅 | 1.36 | 3 |
| 전설 | 1.50 | 4 |

각인 1개 및 보스 고유 효과는 추가 옵션 수와 별개. 수치 예산은 SKILL_BALANCE 10절. 옵션을 고치기 위해 필수 재화를 반복 파밍하는 구조를 기본으로 하지 않는다.

## 2. 무기 유형 — 처음에는 6종 가안
| 유형 | 전투 정체성 | 기본 옵션 경향 |
| --- | --- | --- |
| 한손검 | 범용 근접, 안정적인 한 타격 | ATK/DEF |
| 대검 | 무거운 타격·넓은 전방 공격 | ATK/HP |
| 단검 | 짧은 사거리, 빠른 연속 적중과 치명타 | ATK/치명 |
| 둔기 | 강한 타격, 방어 약화/탱킹에 적합 | ATK/DEF |
| 활 | 충전 원거리 발사, 실제 화살과 모델/당기는 모션 | ATK/치명 |
| 지팡이 | 마력탄·기술/치유/소환 지원 | SKL/ATK/HP |

무기의 공격 범위/속도/계수는 실제 Bedrock 지원 범위 시험 후 확정. 동적 공격속도 버프를 보장하지 않는다. 느린 대검에 높은 1타, 단검에 낮은 1타와 빠른 공격 간격 등의 차이는 **후보**이며 실제 피격 무적시간과 공격 입력이 성립해야 적용. 무기마다 고유 실루엣·아이콘·텍스처/모션을 확보. 바닐라 무기는 사용 가능. RPG 방패(오프핸드, 방어 중심)는 추가 검토, 기본 6종과 직업 능력을 종속시키지 않음.

## 3. 방어구·장신구
- 바닐라 장비 슬롯과 호환하는 투구/상의/하의/신발 4부위. 중갑(DEF/HP), 경갑(ATK/치명), 로브(SKL/치유·소환)의 장비군 후보. 직업별 착용 제한/세트 강제 없음. 서로 다른 장비군을 섞을 수 있음. 모델/텍스처 차별화, 바닐라 장비와 중복 방어 계산 금지.
- 장신구: 목걸이 1개 + 반지 2개(동일 개별 아이템 중복 장착 금지) 가안. 모험가의 서 장비 메뉴에서 관리; 기존 바닐라 핫바/갑옷 슬롯은 변경하지 않음. 장신구는 SKL/치명/회복/소환/HP 등 빌드 조정 중심, 추가 스탯 예산은 총 장비 밸런스에 포함. 실제 가상 슬롯 데이터/장착·저장 구현 미검증.
- 추가 슬롯으로 기본 DPS/HP가 기존 BALANCE 기준보다 크게 늘어날 수 있으므로 장신구 수치와 고유효과 포함한 직업별 실측 후 조정.

## 4. 랜덤 옵션
- 공통 4스탯 ATK/DEF/HP/SKL, 치명 확률/치명 피해, 회복 효과/소환 피해/보호막 흡수량/이동속도, 조건부 추가타·둔화·지속피해 등.
- 같은 아이템에 동일 옵션 중복 없음. 무기/방어구/장신구별 가중치 다르게: 무기는 공격/기술, 방어구는 체력/방어/보호막, 장신구는 빌드 특화.
- 범용 공격·스탯 옵션만이 정답이 되지 않도록 조건부 옵션에 분명한 이득. 예: 치명타 확률 3~7%p, 회복/소환 효과 6~12% (기존 SKILL_BALANCE 후보 유지), 같은 종류의 전체 합산 상한 적용. 아이템 레벨 상승 시 % 옵션이 무한 증가하지 않는다.
- 추가 옵션의 숫자와 각인 행동 효과를 구분. 추가 옵션은 주로 수치/작은 조건부 효과, 각인은 전투 루프에 영향을 주는 뚜렷한 효과, 보스 고유효과는 그 보스의 개성을 살리는 특수 효과.
- 최초부터 옵션 재굴림/등급 승격/강화 단계/강화 실패를 모두 넣지 않는다. 드롭의 가치 유지. 옵션 변경은 향후 필요할 경우만 추가.

## 5. 각인 — 드롭형 각인서 1개 슬롯(제안)
- 각인서는 몬스터·정예·던전 상자·보스에서 직접 획득하는 소비형 아이템. 사용/모험가의 서에서 장비를 선택하고 미리보기·확인 후 해당 효과를 적용. 성공률 100% 후보, 장비 파괴/실패 없음. 일반 장비도 각인 가능. 각인 해금에 직업 제한/바닐라 XP 소비 없음.
- 장비마다 **각인 1개**. 새 각인 적용 시 기존 효과 교체(확인 표시)하고 새 각인서 1개 소비. 이전 각인서는 복원되지 않는 안; 귀한 각인을 중복 낭비하게 되는지 추후 테스트. 중복 장비의 동일 각인 효과는 하나만 적용(최고 효과 우선), 별도 명시하지 않은 무한 중첩 금지. 여러 각인 효과가 자체 연쇄로 무한 발동하지 않음.
- 장비 유형 제한만 후보(공격 각인은 무기, 방어 각인은 방어구 등); 직업 자체 제한 없음. 적용 전에 허용 여부 표시.
- 드롭률/등급/재활용 재료는 미정. 획득·소비·교체가 간단해야 하며 별도 화폐/각인 레벨업 트리/복잡한 가공대 강제 없음.

## 6. 보스 고유 장비와 일반 파밍
- 고유 장비는 별도의 6번째 희귀도가 아니라 **아이템의 고유 효과/외형** 구분. 희귀도 5단계와 공존. 보스 고유 드롭은 이후 보스 상세 기획과 함께 결정.
- 예시: 거대한 수호자에서 얻는 대검의 특정 타격에 추가 충격파; 언데드 보스의 지팡이에서 얻는 소환 보조; 보스의 갑옷이 강타를 막으면 짧은 보호. 이들은 확정 보스/효과가 아님.
- 일반 야생 적: 일반~고급 장비 중심, 희귀 이상은 가끔; 정예는 희귀~영웅을 노릴 가치; 미니보스·보스·던전 희귀 상자는 고등급/고유 장비 및 각인서 주요 획득처. **일반 사냥에서도 희귀도 상위 장비의 낮은 확률 획득 가능** 가안. 확정 드롭률 미정. 모든 몬스터가 아이템을 대량 떨어뜨려 RPG 가방이 즉시 차지 않도록 조절.
- 쓸모없는 장비는 버리기/가방에서 꺼내기/분해로 정리하는 방안. 분해 시스템은 선택적 편의 기능 후보(재료 활용처 확정 전 필수화하지 않음). 잠금/즐겨찾기·고가품 확인·거래/저장 중복 방지 필요.
- 장비 설명: 이름/희귀도/Lv. → 기본 스탯 → 추가 옵션 → 고유 효과 → 각인. 현재 장착품 비교와 상세 정보는 모험가의 서에서, HUD에 장비 상세를 상시 표시하지 않는다.

## 7. 외부 사례 및 검증
- Minecraft Dungeons 공식 [September Update](https://www.minecraft.net/en-us/article/dungeons-september-dev-blog): 무기 전투 스타일과 행동을 바꾸는 인챈트. 원리만 참고, 자산/UI 복제 안 함.
- Diablo IV 공식 [Loot Reborn](https://news.blizzard.com/en-us/article/24077223/galvanize-your-legend-in-season-4-loot-reborn), [Itemization & Systems Changes](https://news.blizzard.com/en-us/article/24243142/sanctuary-ignites-with-itemization-systems-changes): 랜덤 옵션, 선택형 부여의 장비 커스터마이징. GT RPG는 더 단순한 1개 각인 방식, 다중 강화/재화 없음.
- 직접 플레이·영상 검토·베드락 엔진·모델·UI는 NOT_RUN. 사용자 검토 이후 각인 수치·획득 확률·장신구 예산·무기별 입력/공격 간격을 구체화. 코딩/에셋 제작은 별도 사용자 승인 후.

## 8. 무기 공속·사거리 및 장신구 기술 재조사 (2026-11-24)
### 근접 무기
- 공식 [minecraft:cooldown](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/itemreference/examples/itemcomponents/minecraft_cooldown?view=minecraft-bedrock-stable)의 type=attack은 item format 1.21.130 이상 지원. 무기별 고정 공격 간격 지정 후보. 같은 category 아이템은 쿨타임을 공유하므로 무기 바꿔치기 우회 방지를 시험. [minecraft:swing_duration](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/itemreference/examples/itemcomponents/minecraft_swing_duration?view=minecraft-bedrock-stable)은 **애니메이션만** 조정하며 실제 공격 빈도와 다름.
- [minecraft:piercing_weapon](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/itemreference/examples/itemcomponents/minecraft_piercing_weapon?view=minecraft-bedrock-stable)은 1.21.130+에서 reach(min/max) 및 hitbox_margin을 지정하고 시선 직선상의 여러 엔티티를 공격하며 블록에 가로막히면 피해가 차단된다. 이 속성이 있는 무기는 블록을 파괴할 수 없고 단일 표적만 공격하는 검과는 다르므로 모든 무기에 무조건 적용하지 않는다. [minecraft:kinetic_weapon](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/itemreference/examples/itemcomponents/minecraft_kinetic_weapon?view=minecraft-bedrock-stable)은 상대 속도 기반 돌진형이며 일반 대검 범위 공격과는 다른 기술.
- 부채꼴/원형 범위 공격은 Script API의 [Dimension.getEntities 및 getBlockFromRay/getEntitiesFromRay](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/minecraft/server/dimension?view=minecraft-bedrock-stable)를 이용해 공격 때 근처 적만 조회하고 시선 각도, 거리, 장애물, 적대 여부를 필터하는 후보. 직접 타격 대상 중복, 벽 너머, 아군/소환수 타격 및 추가 공격 재귀 금지. 이벤트 구독/피해 처리 순서와 피격 무적 틱을 실기 검증. playerItemAttackEntity before 이벤트는 pre-release이므로 필수 의존성으로 확정하지 않는다.

| 단검 | 0.5초 | 단일, 짧은 2~2.5블록 |
| 한손검 | 0.7초 | 단일, 3블록 |
| 둔기 | 0.9초 | 단일 또는 좁은 충격, 3블록 |
| 대검 | 1.1초 | 전방 부채꼴 3~3.5블록, 주 대상 외 최대 3명 |

- 공격 간격이 다른 경우 단일 DPS를 비교하여 1타 계수를 조정(예: 기준 한손검 대비 간격 비례에서 시작). 대검 광역성과 단검의 치명타/연격 빈도까지 검토. 단검 0.5초가 엔진 피격 무적시간을 넘지 못할 경우 타격 빈도/판정 재설계. 범위 수치가 확정 또는 실기 성공을 뜻하지 않는다. 바닐라 검·도구에는 임의 쿨타임/채굴 제한을 추가하지 않는다.
- 사례: [Lynx More Weapons](https://www.curseforge.com/minecraft-bedrock/addons/lynx-more-weapons/files/9014837/additional-files)는 piercing_weapon을 이용한 대검/대도끼 3.75블록 사거리를 명시. [Sweep Impact](https://www.curseforge.com/minecraft-bedrock/addons/sweep-impact)는 타격 시 전방 영역을 판정하는 부채꼴 공격, [Java Combat Evolved](https://www.curseforge.com/minecraft-bedrock/addons/java-combat-evolved)는 무기별 쿨타임/범위 공격을 소개. 공개 설명 검토이며 설치 시험/코드 확인/라이선스 재사용 승인 아님. GT RPG는 원본 자산을 복사하지 않고 자체 무기만 차별화.

### 장신구
- 공식 [EquipmentSlot](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/minecraft/server/equipmentslot?view=minecraft-bedrock-stable)은 기존 장비 슬롯만 제공(Body는 비인간형 몹 갑옷용). **기존 플레이어 인벤토리에 반지/목걸이 엔진 슬롯을 직접 추가할 공식 안정 API는 확인되지 않음.**
- 별도 **논리 장착 슬롯**으로 목걸이 1/반지 2 후보 구현: 모험가의 서 → 장비 → 각 슬롯 선택 → 소유 장신구 장착/해제/교체. 바닐라 갑옷·손·핫바 슬롯과 독립. 장착된 실제 아이템은 원래 인벤/가방에서 이동되어 장착 데이터에만 존재하며 고유 ID/레벨/희귀도/옵션/각인/고유 효과를 보존. 서버가 장착 상태에 따른 스탯을 재계산, 클라이언트 메뉴는 표시/요청 역할만.
- 안정 [ItemStack](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/minecraft/server/itemstack?view=minecraft-bedrock-stable) 동적 속성, [Container](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/minecraft/server/container?view=minecraft-bedrock-stable) 입출력 및 Entity/Player 동적 속성은 기반 기능 후보. ItemStack 객체를 동적 속성에 그대로 저장한다는 뜻이 아니며 RPG 아이템의 필요한 데이터를 직렬화하거나 안전한 실제 저장 컨테이너로 보존해야 함. 가방과 장신구 장착 간 고유 ID 중복/분실 방지, 교체/해제 시 빈칸 부족하면 원 상태 유지, 서버 재시작·이탈·직업 변경·죽음/keepInventory 규칙 검증. 가상 장착 장신구 포함 이미 소유한 모든 RPG 장비는 사망 시 보존(장착·일반 인벤·RPG 가방 위치 무관). 미확정 세션 보상은 실패 시 폐기. 중복 복구 방지 및 바닐라 사망 규칙 분리 실기 필요. 갑옷 대체 슬롯 방식은 사용하지 않는다.
- [Novelty API](https://www.curseforge.com/minecraft-bedrock/addons/novelty)는 추가 액세서리 24슬롯, [Easy Accessories](https://www.curseforge.com/minecraft-bedrock/addons/easy-accessories-bedrock-accessories-system)는 전용 메뉴에서 장신구별 슬롯을 제공한다고 소개. 추가 장착 시스템의 실제 공개 사례이나 엔진 고유 인벤토리 슬롯 증설을 증명하지 않는다. 해당 애드온 설치/코드/라이선스는 직접 검증하지 않았으며 종속성 채택은 미결정. GT RPG 자체 가상 슬롯 우선 검토. 모델 외형 표시(반지/목걸이가 플레이어 모델에 실제 보임)는 별도 RP 기술 검증.

## 강화 재도전 보상 연계
기본 보스와 별도로 위협도에 맞춘 강화 재도전에서 동일 고유 장비를 더 높은 레벨로 다시 획득할 수 있다. 고등급/고유 장비 획득 확률 상승 및 상한은 MONSTERS 4.5절 및 추후 보상 설계. 보유 장비 자동 레벨업 없음.
