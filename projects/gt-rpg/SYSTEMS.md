# GT RPG — 공통 시스템 및 메뉴 기획

2026-11-25. 사용자가 공통 시스템 상세 기획 진행에 동의. 아래 메뉴 구성 및 미결정 목록은 검토용 초안. 기존 확정 콘텐츠 및 사망/보상/위협도 규칙 유지. 구현 승인 아님.

## 1. 모험가의 서 메뉴 구성 제안
- 소모되지 않는 모험가의 서를 사용하면 메인 메뉴. 현재 직업/전직명, RPG 레벨/XP, 세계 위협도, 미사용 스탯 포인트를 간결하게 표시. 바닐라 인벤/핫바 유지. 메인 메뉴는 정보 구조이며 최종 UI 디자인 아님.
| 메뉴 | 하위 기능 |
| --- | --- |
| 상태창 | 현재 능력치, 스탯 배분/무료 초기화, 기본/장비/버프 수치 구분 |
| 직업 | 9직업 설명/변경, 레벨·전직 조건/직접 전직, 액티브/패시브 확인 |
| 장비 | 주손·방어구·장신구 현재 장착 상태, 비교, 장착/해제, 각인 적용·교체 |
| 가방 | RPG 아이템 분류/정렬/잠금·이동·정리, 확정 미수령 보상 회수 |
| 세계 위협도 | 현재 W/변화 안내, 승급 신청 및 전원 동의/참가 |
| 콜로세움 | 상대 선택/결투 신청·수락/거절, 진행 중 기권 |
| 모험 안내 | 최초 플레이/성장/장비/던전/위협도 등 필요한 규칙 다시 확인 |
| 설정 | 개인 HUD·연출·알림 관련 설정 후보 |
- 던전 입장은 자연 생성 입구에서만, 메뉴를 통한 무료 무한 재도전/순간이동 없음. 던전 진행 중에는 세션 상태/예정 전리품/포기 경로를 상황에 맞게 제공(구체 정책 후속). 각인은 장비 메뉴 내 기능으로 두고 별도 메인 메뉴를 늘리지 않음.
- 하위 메뉴에서 뒤로/닫기 경로 일관성, 현재 선택 항목/스크롤·필터 복귀, 모바일에서 작은 버튼/과도한 창 전환 지양. 안전한 상태 변경 및 전투 중 직업 변경/장비 이동 등 제한은 후속 상세화. 모험가의 서 재발급 경로 필요.
- 참고: [Wynncraft Skill Points](https://wynncraft.wiki.gg/wiki/Skills) 나침반 메뉴를 통한 스탯 배분, [Character Menu](https://wynncraft.wiki.gg/wiki/Character_Menu) 직업/캐릭터 정보 접근; [Minecraft Dungeons Inventory](https://minecraft.wiki/w/Dungeons%3AInventory) 소유 장비/장착 상태/성장 정보 통합, [Enchantment](https://minecraft.wiki/w/Dungeons%3AEnchantments) 장비별 강화 표시. 현재 검색 결과의 공개 설명을 검토. GT RPG에는 나침반 대신 책, 직업별 성장 기록, 바닐라 인벤 유지, 각인 별도 규칙. 원작 화폐·스킬 트리/장비 제한/UI 자산을 복제하지 않음. 실제 화면/영상·Bedrock 모바일 실기·최종 디자인 검증 NOT_RUN.

## 2. 시스템 기획 잔여 목록
핵심 콘텐츠가 존재한다는 것과 전체 플레이 흐름이 설계되었다는 것을 구분한다. 아래는 GAME_DESIGN, EQUIPMENT, HUD_DESIGN, DEVELOPMENT_PLAN, DECISIONS 및 앞서 작성한 던전/승급/PvP 문서의 범위를 대조한 잔여 기획 목록. 새 기능 채택을 뜻하지 않는다.
| 순서 | 분야 | 남은 결정 |
| --- | --- | --- |
| S1 | 책/메뉴 | 정보 구조 검토, 최초 접속·직업 선택·책 지급/재발급·짧은 안내 |
| S2 | 가방·장비·각인 | 54칸 전체/분류별 용량·스택 규칙, 바닐라 아이템 저장 범위, 야생 드롭 수령, 장비 비교/장착/잠금/정렬/일괄 처리, 가방 만석/확정 보상 회수, 각인 소비·교체 및 분해/친구 거래 필요성 |
| S3 | 성장 관리 | 스탯 수량 입력/미리보기/무료 재분배, 직업 전환 가능 조건/기존 체력·CD·소환수, 전직 및 스킬 설명/안내 |
| S4 | 월드·생존 연동 | 초심자 보호 구역 정의 및 이동/스폰 레벨, 지역/바이옴·차원·주야·스포너 처리, 엔더 드래곤/위더/워든의 RPG 레벨·피해·보상 여부, 바닐라 장비 스탯/인챈트/환경 피해와 RPG 상호작용 |
| S5 | 공통 전투·협동 | 실제 기여 인정(직접/소환/유효 치유·보호·버프), 무기 입력/피해 경로, 아군·중립 적대 및 소환수 표적·이동/차원 복귀·사망 정리, 세션 탈퇴/재접속, 약물·음식·회복 등 충돌 |
| S6 | 편의·설정 | 알림 우선순위/빈도, HUD/이펙트/성능 설정, 기본 사용법 안내. 도감/분해/거래 등은 필요성이 확인될 경우에만 채택 |
| S7 | 아트·음향 | 장비/몬스터 외형 레퍼런스·아이콘/모션·효과음·전투 예고, 던전별 실제 공간 설계, PC/모바일 UX 검수 계획. 구현 전 해당 분야 실제 외부 사례 조사 및 합법적 자산 확보 |
| S8 | 저장·검증 | 데이터 권위/ID/스키마·업데이트 호환·보상 정산·재접속/실패 복구, M0 기술 실험 및 이후 실기 기준. 엔진에서 확인해야 할 세부는 M0/M1로 분리 |
- 별도 퀘스트·전직 재료·의무 경제/상점·전문직·업적·복잡한 신규 성장 트리는 기존 핵심 루프에 필수 아님. 사용자 요청 없이 추가하지 않는다.
- 수치 가안의 모든 항목을 미리 확정하거나 직업별 DPS를 강제 균등화하지 않는다. 사용자 요청대로 개성/성장 체감/실제 문제 중심. 구조·규칙을 먼저 정하고 엔진 제약/실측에 따른 수치 조정은 구현 승인 이후.
- 이번 감사는 핵심 흐름/문서의 누락 검토이지 모든 코드 경로, 스킬 계수 및 외부 링크 전수 감사가 아니다. 현재 실제 구현 없음. 다음 기획: S1 메뉴 승인/첫 접속 및 S2 가방·장비·각인 구체 규칙.
