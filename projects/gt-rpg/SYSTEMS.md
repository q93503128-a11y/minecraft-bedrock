## 1. 모험가의 서 메뉴 구성 제안
- 소모되지 않는 모험가의 서를 사용하면 메인 메뉴. 현재 직업/전직명, RPG 레벨/XP, 세계 위협도, 미사용 스탯 포인트를 간결하게 표시. 바닐라 인벤/핫바 유지. 메인 메뉴는 정보 구조이며 최종 UI 디자인 아님.

| 상태창 | 현재 능력치, 스탯 배분/무료 초기화, 기본/장비/버프 수치 구분 |
| 직업 | 9직업 설명/변경, 레벨·전직 조건/직접 전직, 액티브/패시브 확인 |

## 3. RPG 가방과 바닐라 인벤의 역할 — 검토용 제안
- 사용자 질문: 두 인벤 사이 왕래와 실제 무기/갑옷 착용. 권장안은 RPG 가방을 전용 보관 공간으로, 기존 바닐라 인벤/핫바/갑옷 슬롯을 실제 사용 공간으로 유지. 일반 블록/음식/도구/바닐라 장비는 일반 인벤, RPG 장비/각인서/전용 재료만 RPG 가방 저장 후보. 최신 사용자 방향: 카테고리별 독립 용량으로 변경. 무기/방어구/장신구/각인서·RPG 재료 각각 54칸, 총 216칸을 초기 가안으로 제안. 일반 장비는 개별 슬롯, 동일 효과/종류/메타데이터의 각인서·재료만 중첩 허용 후보. 용량 구매/확장권 미도입.
- RPG 아이템은 가방↔일반 인벤 양방향 이동 가능. 가방 안 무기/갑옷은 실제 장착하지 않은 상태이며 능력치 미적용. 가방에서 꺼내 일반 핫바/갑옷 슬롯으로 사용하거나 가방 상세의 장착 버튼으로 실제 슬롯에 이동하는 편의 기능 후보. 교체 대상은 빈 일반 인벤/가방 공간으로 안전 이동, 공간 부족 시 원 상태 유지. 바닐라 인벤에서 직접 착용/교체하는 기존 조작도 유지. 장신구만 기존 가상 슬롯 사용, 실제 장착 ID는 단일 소유 위치에만 존재.
- 던전/승급 확정 RPG 보상은 기존 가방 자동 지급 및 만석 시 확정 보상 회수 대기 유지. 야생 RPG 드롭도 가방 우선 자동 지급 후보(가방 만석이면 일반 인벤 또는 정상 드롭 처리 검토, 무한 보관함으로 악용 금지). 바닐라 정상 드롭은 기존 방식. 가방↔일반 인벤↔장착 간 이동은 아이템 복제가 아닌 실제 소유 위치 변경. 장비 고유 ID/옵션/각인/레벨 보존, 실패/재접속 시 일관성 검증. 기존 사망 보존 정책 유지.
- 공식 [Container](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/minecraft/server/container?view=minecraft-bedrock-stable)에서 플레이어 일반 인벤 36슬롯 및 아이템 조작, [EntityEquippableComponent](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/minecraft/server/entityequippablecomponent?view=minecraft-bedrock-stable)에서 기존 장비 슬롯 접근 기능 문서 확인. RPG 가방 자체가 엔진 인벤 확장이라는 의미 아님. [Epic Backpacks](https://www.curseforge.com/minecraft-bedrock/addons/epic-backpacks)의 제작자 설명은 양쪽 인벤 한 화면/탭 이동 사례, [Minecraft Dungeons News](https://www.minecraft.net/ko-kr/article/minecraft-dungeons-news)의 공식 설명은 장비/강화 통합 정보 구성 참고. 실제 설치/화면 조작/라이선스 검증 미실행. 동시 인벤 화면 가능 여부 M0 검증, 불가능하면 메뉴 기반 이동/장착. 최종 디자인 확정 아님.
- 사용자 요구: UI/UX/HUD는 단순하고 가독성 높으며 무난하게 예쁘고 Minecraft 분위기와 일치. 사용자가 Minecraft Dungeons식 장비 UI 방향 선호 및 레이아웃 재현 요청. 실제 플레이 화면을 기준으로 정보 배치·슬롯·크기 비율을 재현하고 필요한 슬롯만 추가. 원작 코드/텍스처/폰트 등 사용 권한 없는 리소스의 추출·저장소 게시·재배포 금지. 합법적 외부 에셋을 우선. 최종 화면은 미제작. HUD_DESIGN의 기존 시야/생존 조작 우선 유지. 초기 디자인 방향은 바닐라 슬롯/테두리/픽셀 아이콘 및 간결한 장비 비교/희귀도 강조. 실제 외부 사례 화면과 PC/모바일 검수 후 최종 디자인. 과한 장식/임의 코드 도형으로 최종 아트 대체 금지.

## 4. 장착 화면 및 카테고리별 용량 최신 방향
- 던전스식 장비/인벤 화면을 기준 레이아웃으로 삼는다. GT RPG 주무기 1, 바닐라 갑옷 4, 목걸이 1, 반지 2의 기존 총 8슬롯을 반영(보조 손은 기존 바닐라 슬롯 그대로, 상태 표시 후보). 사용자의 장착 칸 추가 언급은 던전스 화면을 기존 GT RPG 장착 규칙에 맞춰 확장하는 것으로 해석. 신규 장착 부위/추가 장신구 수를 임의로 만들지 않는다.
- 사용자 방향: 카테고리별 용량. 각 54칸(무기/방어구/장신구/각인서·RPG 재료), 합계 216칸은 초기 수치 가안이며 확정 실측 용량 아님. 동일 각인서·재료 스택은 메타데이터 일치 시에만. 장착 슬롯은 가방 용량과 분리. 각 카테고리 만석이면 다른 카테고리로 넘기지 않고 확정 보상 회수 대기 등 기존 정책을 적용. 잠금·정렬·장착·이동 등 세부 후속. 실제 UI/저장/성능 NOT_RUN.

## 5. 가방 조작·장착·각인·친구 거래 — 검토용 세부안 (2026-11-25)
기존 사용자 방향: Minecraft Dungeons식 레이아웃, 카테고리별 독립 용량(각54/총216 가안), 실제 핫바/갑옷과 가상 장신구 슬롯, RPG 장비 사망 보존. 아래 신규 조작 규칙은 검토용이며 구현 승인 아님.
### 5.1 가방 및 정리
- 네 카테고리 탭(무기/방어구/장신구/각인서·RPG 재료), 사용량/용량 표시. 장비는 고유 ID별 1칸, 동일 타입/메타데이터의 소비형 각인서·재료는 스택 허용(초기 최대64 가안). 일반 바닐라 아이템은 일반 인벤에서 관리.
- 정렬 최근 획득순·레벨순·희귀도순, 동일 순위는 고유 ID로 안정적 정렬. 필터 장비 종류/희귀도/잠금 여부. 정렬은 소유권 변경 아님. 장비 상세 선택 및 돌아오기 시 카테고리/필터 유지. 자동 삭제 없음.
- 잠금 토글: 장비별 잠금 상태 저장. 잠금 상태로 착용/해제/보관/비교 가능, RPG 메뉴의 삭제·거래 금지. 각인 변경은 명시적 확인을 요구. 바닐라 일반 인벤에서의 버리기/상자 이동 등 엔진 조작까지 잠금 강제 가능한지는 M0 확인하고 제한 명시.
- 일괄 정리: 해당 카테고리에서 레벨 이하/희귀도 이하 조건 선택(둘 다 고르면 AND), 대상 목록·개수 미리보기 후 확정 삭제. 잠긴 장비·장착 장비·전설·보스 고유·각인 장비는 일괄 삭제에서 항상 제외. 직접 삭제는 잠금 해제 및 별도 확인 후 가능. 거래/장착/보상 변동으로 대상이 바뀌면 재확인, 자동 정리/무확인 삭제 금지.
- 일괄 보관: 바닐라 인벤의 RPG 아이템만 해당 카테고리로 옮김. 현재 주손 및 장착 장비는 제외. 가방이 꽉 차면 이동 가능한 만큼만 이동, 나머지는 원위치. 개별 꺼내기/넣기도 지원.
- 야생 RPG 드롭은 가방 우선 자동 지급, 만석이면 바닐라 빈 인벤 칸으로, 둘 다 만석이면 정상 월드 드롭 후보(개인 귀속/다른 플레이어 줍기 정책 및 알림 실기 검증). 던전/승급의 성공 확정 RPG 보상은 가방 만석 시 기존 확정 보상 회수 대기 유지(야생 무한 보관함은 추가하지 않음). 회수 화면은 가방 하위, 공간이 있는 만큼만 수령; 확정 보상은 기간 만료로 삭제하지 않음. 일반 보상은 일반 인벤 우선, 만석 시 확정 보상 회수 대기. 미확정 보상과 구별.
### 5.2 장비 비교와 실제 장착
- 기존 장착 8슬롯 및 바닐라 보조 손 상태를 표시. 선택한 장비와 해당 실제 장착 부위의 장비, 기본/추가 스탯·고유 효과·각인·희귀도·레벨, 착용 시 총 스탯 증감을 표시. 단일 전투력 점수로 좋고 나쁨 강제 판단하지 않음. 반지 2칸은 교체 대상 선택. 직업 착용 제한을 추가하지 않음.
- 가방에서 장착 버튼: 무기는 현재 선택한 핫바 슬롯으로, 갑옷은 해당 실제 장착 부위로, 장신구는 해당 논리 슬롯으로 이동. 교체되는 RPG 장비는 비워진 해당 가방 슬롯 또는 빈칸, 바닐라 장비/아이템은 일반 인벤 빈칸(원본 가방으로 잘못 옮기지 않음). 대상 공간이 부족하면 전체 교체 취소. 일반 인벤에서 직접 착용/교체 가능. 해제 역시 적절한 저장 공간 없으면 원상 유지. 아이템 복사 아님.
- 장착/해제/이동 직후 서버 스탯 갱신, 실제 HP 비율 보존 후보(장비/직업 교체로 무료 회복 방지). 메뉴는 실제 보유 상태와 일치. 바닐라 엔진 장착과 논리 슬롯의 구체 연동은 M0/M1 검증.
### 5.3 각인 적용
- 장비 상세 → 각인 → 사용 가능한 각인서만 표시 → 현재 각인/새 각인 효과 비교 → 확인. 장비당 각인 1개, 적용 성공률100%, 각인서1개만 소비, 장비 파괴/추가 골드/바닐라 XP 소비 없음. 기존 각인 교체 시 이전 각인은 소멸(환급 없음 초기안), 동일 각인 재적용 불필요 시 소비 없이 차단. 장비 유형 제한은 EQUIPMENT 표, 직업 제한 없음. 여러 장비에 동일 각인 최고 효과만 적용 가안 유지.
- 장비/각인서가 실제 소유·사용 가능 상태이며 선택 직후와 동일한지 최종 검사. 재클릭·중단·이탈/동시 이동에서도 소모/각인 한 번만 적용 또는 둘 다 취소. 미확정 보상·타인 아이템 사용 금지. PvP 중 각인 변경 금지.
### 5.4 거래와 불필요한 재료 정리
- 친구끼리 RPG 장비·각인서·전용 재료를 건넬 수 있도록 한다. 초기 추천은 근처 접속자 대상 1방향 선물(가방 상세의 건네기 → 상대 선택/아이템 정보 확인 → 상대 수락 → 소유권 이동). 서로 아이템을 교환하는 별도 에스크로 거래소·상점·화폐·경매장은 초기 미도입. 바닐라 아이템 교환은 기존 방식. RPG 아이템 일반 인벤 드롭/상자 전달 시 실제 고유 ID·메타데이터 보존 검증. 성공 전 세션 보상 및 잠긴 아이템/장착 장비는 선물 불가. 양쪽 세션 참가 중에는 금지. 거리/수락 유효시간/수령 공간 확인, 만석·거절·이탈 시 원소유 유지. 선물 기능 세부 및 추가 개발 비용은 검토용.
- 분해는 별도 화폐나 활용처가 없는 현재 구조에 강제 도입하지 않음. 초기에는 안전한 개별/일괄 삭제 및 친구에게 주기. 추후 재료의 실제 용도가 정해지면 분해 기능 검토. 각인서 획득률/종류를 위해 불필요한 분해 재화 추가 금지.
### 5.5 참고와 검증
- 실제 확인한 공개 설명: [Minecraft Dungeons Inventory](https://minecraft.wiki/w/Dungeons%3AInventory)의 장비 상세와 Salvage 버튼, [Enchantment](https://minecraft.wiki/w/Dungeons%3AEnchantments)의 장비별 강화 정보; [Terraria Inventory](https://terraria.wiki.gg/wiki/Inventory)의 즐겨찾기 보호와 정리 기능. GT RPG는 상세/조작 배치 및 실수 방지 원리를 참고하고 에메랄드·인챈트 포인트·분해 경제·Terraria의 즐겨찾기 정렬 방지까지는 강제하지 않는다. 사용자 요구의 던전스 레이아웃 우선. 현재 웹 검색 설명만 확인, 실제 화면/영상/모바일 조작/라이선스·구현 검증 NOT_RUN.
- 회귀 테스트: 모든 카테고리 만석·스택 경계, 잠금/일괄 삭제 안전, 일반/RPG 장비 교체·원위치 복구, 착용 스탯 실제 반영, 각인 소모와 교체, 동일 ID 중복/아이템 유실, 선물 수락/취소/동시 요청/재접속, 확정 보상 부분 회수, PC/모바일 레이아웃/터치·스크롤. 모두 NOT_RUN.
- 다음 기획: 최초 접속/모험가의 서 재발급, 스탯 배분·직업 변경·전직 관리(S1/S3), 월드·생존 연동(S4). 기존 단계 유지.

## 6. 최초 접속·스탯·직업 관리 — 검토용 상세안 (2026-11-25)
기존 확정: 9직업/독립 성장 기록, 첫 직업 선택 시 플레이어당 1회 기본 RPG 무기, 레벨당 자유 3점, 무료 재분배, 수동 1~6차 전직. 아래 신규 UX/안전 조건/시간/기본 지급 품목은 제안이며 구현 승인 아님. 시각 디자인은 실제 레퍼런스 기반 후속 제작.

### 6.1 첫 접속과 모험가의 서
- 최초 플레이어 등록 시 모험가의 서 지급, 직업 선택 메뉴를 한 번 안내. 바닐라 기존 월드 및 기존 인벤을 변경하거나 강제 텔레포트하지 않는다. 최초 선택을 닫으면 책으로 다시 열 수 있으며 반복 팝업으로 조작을 방해하지 않는다. 미선택 상태에서도 바닐라 생존은 가능하나 직업 XP/스킬은 선택 후 시작; 이 경계는 기술 검증.
- 선택 화면: 전사(근접), 궁수(다중 사격/원거리), 마법사(원소/광역), 암살자(치명타/단일), 성기사(생존/보호), 드루이드(지속 회복/동물), 골렘술사(골렘), 네크로맨서(언데드 군단), 사제(회복/보호막/강화). 직업명, 실제 액티브 및 1차 패시브 간단 설명, 선호 무기 및 역할만 먼저 제시. 상세 설명은 선택적으로 열기. 직업마다 Lv.1 기록 최초 생성, 첫 직업 확인 후 기존 1회 지급 정책 적용. 이후 직업 선택 변경은 무료.
- 초기 지급 무기 유형 후보: 전사 대검, 궁수 활 및 첫 지급에 한해 일반 화살 32발, 마법사 지팡이, 암살자 단검, 성기사 한손검, 드루이드 지팡이, 골렘술사 둔기, 네크로맨서 지팡이, 사제 지팡이. 모두 Lv.1 일반 등급. 선호 무기 예시일 뿐 직업 착용 제한 없음. 일반 인벤 빈칸 우선, 부족하면 해당 RPG 가방/일회 지급 대기. 일반 화살은 일반 인벤/지급 대기. 최초 선택/장비 지급을 중단·재시작 시 누락/복제하지 않음. 직업 변경으로 새 지급 없음.
- 첫 선택 후 현재 직업 액티브 조작 안내(PC/모바일 실제 검증된 입력), 책/스탯/전직/가방 사용은 짧은 상황별 안내. 별도 튜토리얼 맵/강제 퀘스트/보상 수집 의무 없음. 모험 안내에서 다시 열기, 첫 안내는 끄기 가능.
- 책은 소모되지 않는 개인 메뉴 접근용. 접속/리스폰 및 저빈도 상태 확인으로 보유 여부를 확인하여 분실 시 자동 재발급(빈 일반 인벤 칸 생긴 뒤). 책 자체의 장비 스탯/판매/선물/분해 가치 없음. 다중 복사본이 있더라도 동일 기능, 중복 지급·인벤 덮어쓰기 금지. 타인의 책을 사용하더라도 사용자 자신의 데이터만 접근. 재발급의 실제 입력/탐지 비용 및 엔진 조작 제한은 M0 시험.

### 6.2 스탯 배분
- 상태창은 현재 직업/레벨/XP 및 ATK·DEF·최대 HP·SKL 총합, 미사용 포인트를 표시. 장비/버프 등 상세 내역은 펼쳐 확인. 자유 배분은 현재 직업의 네 스탯만 가능.
- 레벨당 3포인트, 초기안의 투자 환산 ATK+1/DEF+1/HP+4/SKL+1 유지. +/- 버튼 및 수량 단위 1/10/100/최대 또는 직접 정수 입력 후보(모바일에서 고레벨 수백 번 터치 금지). 실제 남은 포인트에 맞춰 제한. 변경 전후 스탯과 남은 포인트 미리보기 → 적용/취소. 메뉴 내 임시 배분은 저장 전 확정 아님. 무료 초기화는 자유 투자만 전부 반환, 레벨 자동 증가/장비/전직 보너스 보존. 초기화·재배분은 같은 화면에서 미리보기 후 적용.
- 서버가 최신 포인트/직업/레벨/세션을 재검사. 음수/소수/범위 초과/중복 제출 금지. 열린 메뉴 중 레벨업하면 최신 포인트 반영 또는 재확인. 실제 HP 최대치가 변경되면 기존 체력 비율을 보존하는 후보(반복 교체/반올림으로 무료 회복 금지). 사망 상태에서 재분배로 부활 불가.

### 6.3 직업 변경과 수동 전직
- 책의 직업 화면에서 9직업의 저장된 레벨/전직 상태(미플레이 Lv.1 표시), 역할, 액티브 및 해금 패시브 확인. 현재 직업 표시. 선택 후 변경 확인. 기존 진행은 독립 저장, 새 직업은 Lv.1부터, 가방·실제 장비 공유. 최초 무료 무기 재지급 없음. 별도 직업 변경 재화/재료/장소 제한/일일 횟수 제한 없음.
- 악용 방지 후보: 최근 실제 적대 피해를 주거나 받은 뒤 10초 동안 직업 변경·스탯 확정/초기화·전직 및 각인 변경 제한. 던전/승급/PvP 참가 중은 해당 변경 금지(전직 조건을 충족해도 종료 후). 일반 인벤 무기 교체/활·도구 사용은 생존 조작이므로 무조건 금지하지 않는다. 상태창·스킬 확인 등 읽기 전용 메뉴는 열 수 있음. 실패 이유/남은 시간만 간단 표시. 10초는 실기 후 조정할 가안.
- 직업 변경 시 이전 직업 소환수/직업 전용 임시 버프·표적·발동 카운터 정리. 바닐라 상태효과·허기·인벤 보존. HP 비율 보존 후보. 직업별 액티브/내부 CD 만료 상태 보존, 이전 직업 CD 우회 방지를 위한 공유 액티브 잠금(기존 액티브 잔여시간까지) 후보. 소환수 재생성은 기존 직업의 정상 소환/재충전 규칙, 변경으로 회복/부활/군단 중복 금지. 실제 정책/지속 타이머는 M0/M1 검증.
- 수동 전직: 직업 Lv.10/20/30/40/50 도달 시 짧은 알림 및 직업 화면 전직 가능 표시. 현재 단계/다음 전직명/신규 패시브/강화 효과/영구 스탯 보너스 표시 → 직접 확인 후 한 단계 전직. 늦게 진행하면 이미 달성한 다음 전직도 순서대로 가능; 중복 스탯 지급 금지. 레벨 및 XP는 그대로, 미사용 포인트도 유지. 재료/퀘스트 없음. 6차 이후 레벨 성장 유지.
- 직업 스킬 상세: 1개 액티브 및 현재 해금된 패시브, 다음 전직에서 무엇이 추가/강화되는지 확인 가능. 실제 피해 계수/발동률·CD는 데이터와 동기화, 미해금 전체 설명은 선택적으로 펼치기. 스킬 슬롯 추가/별도 스킬 포인트 트리 없음.
